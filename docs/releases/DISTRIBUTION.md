# 安装包分发

安装包本体不随仓库分发（单包约 150 MB，且内含第三方版权美术资源），对外发布在 GitHub Releases。仓库内只保留各版本的发布说明与校验值。

各版本说明：[0.1.6](v0.1.6-notes.md) · [0.1.5](v0.1.5-notes.md) · [0.1.3](v0.1.3-notes.md) · [0.1.3 校验值](v0.1.3-CHECKSUMS.sha256) · [项目修改索引](MODIFICATION_INDEX.md)

## 当前测试安装包

当前版本：**`0.1.6-8FEC-D8D4-2DF2`**，Android内部构建号1015，首个启用任务系统（24 节点 / 40 任务）、英雄等级、装备/技能栏强化与 ANR 修复的测试包。

上一版本 `0.1.5-43F5-2A26-0D22`（1013）含前轮战斗修复，新增六卡成长、冰霜/中毒隔离、无敌斩D2/D3触发与旧层兼容。

同一基础版本的小更新仅更新随机索引与内部构建号；基础版本只在明确的内容版本升级时变更。`0.1.3`的早期误标历史包仍只作取证保存。

`v1.0-preview/` 是采用旧编号的历史包，保留用于核对旧测试证据，不代表当前正式版本。

## 本地构建

安装包由本地构建产出到 `dist/` 下，该目录已被 `.gitignore` 排除。构建产物命名与版本登记约定见 [命名规范](NAMING.md)。
