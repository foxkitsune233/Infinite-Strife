# Infinite Strife 0.1.6 — 任务系统正式启用

首个启用任务系统的测试版本。合并了协作者 TIP-SoNg 的任务进度分支，并修复了打开「整备」必现的 ANR。

## 主要更新

- **任务系统上线**：24 个节点 / 40 个任务，含难度分级（简单→噩梦）、三选一节点与地下城解锁；进度在战斗结算时自动推进，复用现有存档字段，不破坏旧档。
- **英雄等级**：可用金币升级英雄等级，营地新增「英雄等级」直达入口。
- **装备 / 技能栏强化**：守卫槽与库存整理规则收紧，二进制存档升级到 v15。
- **修复打开「整备」必现 ANR**：根因是美术缓存过小导致主线程解码风暴；缓存上调至 64 MB、图标解码降到 160 px，掉帧从约 5.7 s 降到约 1.9 s。
- **营地直达按钮**：在原本较空的营地页新增「委托任务」「英雄等级」两个按钮，一键进入对应面板。
- **任务面板「单节点可见」**：一次只显示当前节点，领取后自动移出并露出下一节点，不再一次性列出全部 24 个。
- **应用内版本日志**：补充 0.1.6 条目，首次启动弹出「版本更新」。
