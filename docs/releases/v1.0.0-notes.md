## 主要内容

- 完整任务后剧情框架、英雄加入对话与登顶黑屏字幕结局。
- 20 层转生爬塔、永久等级上限、魔晶、神杖、圣剑与转生道具循环。
- 新增刃甲、天堂之戟、血棘、深渊之刃、羊刀、虚灵之刃、希瓦的守护、达贡之神力、金箍棒、永恒之盘、否决坠饰、风之杖和大隐刀等机制装备。
- 新成装及下级合成进入统一触发系统；补齐驱散、破被动、反伤、放逐、幽灵形态、低血保护等战斗机制。
- 17 张新装备与合成部件使用原创彩绘图标，不直接复用 Dota 物品原图。

## 迁移定位

1.0.0 是 Android 版本的稳定基线。后续主要开发迁移到 Godot；在 Godot 追平以前，Android 包继续作为玩法、数值、剧情与美术资源对照。
