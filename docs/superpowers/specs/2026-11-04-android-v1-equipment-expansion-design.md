# Android 1.0 装备扩展设计

## 目标

在既有 Android 单挑战斗、局外合成、装备主动/自动模式和六格生效栏之上，增加一批能够真实参与战斗的 Dota 风格装备与下级合成件，为 1.0 正式版补足数值构筑、反制构筑和英雄针对性构筑。

## 范围

本批交付 12 件新增成装：刃甲、血棘、深渊之刃、邪恶镰刀、虚灵之刃、希瓦的守护、达贡之神力、金箍棒、永恒之盘、否决坠饰、风之杖与大隐刀；并对既有天堂之戟执行配方/自动释放回归。每件成装均通过局外合成获得，所需的下级件、卷轴、商店目录、图鉴和图标映射一并补齐。

本批不做移动速度、地图位移、隐身、多人范围选择、幻象、召唤物或刷新全部冷却。原版范围技能在一对一中只作用当前敌方英雄。

## 反制定位

- 否决坠饰：清除敌方可驱散正面增益，并施加短时“禁益”。它特别克制 Nec 的幽冥护盾、亚巴顿的可驱散护盾/治疗强化和装备主动增益；不施加破坏。
- 大隐刀：不实现隐身。其下级“幻影斗篷”提供攻击与闪避；大隐刀主动对当前敌方施加破坏，使英雄被动失效。它不关闭装备、卡牌或羁绊效果。
- 风之杖：把旋风简化为当前敌人的短时禁锢；禁锢双方不能行动、目标不能受伤，结束后正常继续战斗。
- 永恒之盘：低生命第一次自动触发，强驱散自身、给予短时保命窗口与护盾；每场战斗每件只能触发一次。
- 刃甲：反射实际承受的生命伤害与护盾伤害；反射伤害不可吸血、不可触发命中、不可再次反射。

## 战斗能力与数据边界

新内容只增加五种明确运行时能力：反伤、必中、禁益、禁锢、低血一次性保命。其余效果复用已有的沉默、眩晕、妖术、破坏、驱散、护盾、减速、暴击、攻速、护甲、魔抗、冷却缩减和主动物品冷却系统。

金箍棒的必中仅跳过目标的闪避判定，不穿透普攻保护。主动伤害与反伤均保留来源 ID 和攻击分类，避免递归。所有新增状态必须随既有战斗快照存档、读档和校验保留。

## 合成链

- 刃甲：锁子甲 + 阔剑 + 卷轴。
- 血棘：紫怨 + 水晶剑 + 卷轴。
- 深渊之刃：碎颅锤 + 先锋盾 + 卷轴。
- 邪恶镰刀：神秘法杖 + 虚无宝石 + 终极法球 + 卷轴。
- 虚灵之刃：幽魂权杖 + 鹰歌弓 + 卷轴；幽魂权杖由魔力法杖 + 空灵挂件 + 卷轴合成。
- 希瓦的守护：板甲 + 神秘法杖 + 卷轴。
- 达贡之神力：魔力法杖 + 皇冠 + 卷轴；本批只制作一级，不做 I–V 反复升级。
- 金箍棒：恶魔刀锋 + 标枪 + 卷轴。
- 永恒之盘：活力之球 + 能量之球 + 卷轴。
- 否决坠饰：圣者遗物 + 铁意头盔 + 卷轴。
- 风之杖：魔力法杖 + 虚无宝石 + 卷轴。
- 幻影斗篷：闪避护符 + 攻击之爪 + 卷轴；大隐刀：幻影斗篷 + 恶魔刀锋 + 卷轴。

价格、尺寸、门槛与首轮数值是本游戏平衡值，不宣称复刻 Dota 当前补丁。全部新成装进入装备主目录；卷轴和中间件进入现有商店/背包/合成目录。

## 验收

单元测试覆盖：目录、配方、唯一组、主动/自动释放、反伤不递归、必中与闪避、否决拆除 Nec 护盾而不拆负面状态、大隐刀仅破英雄被动、风之杖禁锢、永恒之盘单场只触发一次，以及战斗状态的存读校验。每一批通过对应单测和 Android Debug 编译后再进入下一批。
