# 手动战斗操作与终结演出设计

我方技能和主动装备改为手动按钮；敌方继续调用既有自动施放逻辑。按钮只调用 `BattleEngine.command()`，不保存 UI 状态或修改数值。战斗结束由语义结果触发定格、败方下沉淡出、胜方强调和结果面板渐入。

音频由 `BattleAudioBus` 统一映射点击、命中、暴击、技能、胜负。第一版通过 Godot 的 `AudioStreamGenerator` 合成短提示音，因此不引入未审查音频文件；后续可以用 Kenney CC0 资源替换同一映射。

范围和持续特效继续从事件产生，手动按钮仅决定何时发出事件。动画关闭时仍可点击，并保留数值、按钮状态和结果。
