# 0.1.5 新英雄美术资产设计

## 目标

为敌法师、斧王、虚空假面、军团指挥官建立一套能直接接入当前安卓战斗回放、卡牌和角色选择页的卡通化 2D 资产。画风延续现有高饱和度、粗黑描边、Dota 气质与小冰冰式易读剪影；人物不含文字、水印、场景特效或 UI 边框。

本批只制作角色、普攻动作和头像设计。技能特效由用户后续单独决定，因此人物图只保留清晰的手部、武器与脚底落点，绝不把技能光效烘焙进帧图。

## 已批准的技术规格

| 项目 | 规格 |
| --- | --- |
| 朝向 | 右侧。左方单位由运行时镜像，不生成第二套。 |
| 单帧画布 | 512 × 512 px，透明背景。 |
| 角色落点 | 脚底根点固定在 `(256, 464)`；主体不跨越画布底边。 |
| 攻击序列 | `ready → windup → strike → recovery` 四帧。 |
| 动画语义 | 命中在 `strike`；高攻速可复用该序列而不重启蓄力。 |
| 输出 | 每英雄一张待机立绘、一张四帧攻击图集、一张头像裁切图、后续卡图用的视觉规范。 |

## 方案选择

### A. 统一图集方案（采用）

每个英雄遵循相同画布、落点、帧数与右朝向。适合已有 `hero-animation-manifest.json` 和 `attack-atlas-v3.json`，最少运行时改动；动作差异通过姿势、武器轨迹和剪影体现。

### B. 每英雄独立帧数方案

为重武器和高速英雄分别制作 4～6 帧，动作表现更细，但运行时、锚点和高攻速节奏都要分支处理。本版不采用。

### C. 动态骨骼方案

将角色拆分成骨骼部件，在运行时摆动武器。可复用但难以保持现有手绘质感，且实现量大。本版不采用。

## 角色设计与动作分镜

### 敌法师（antimage）

- **角色定位**：女性。面部露出、短发或束发，保留破法战士的锋利感；不沿用 PA 的兜帽、面罩、双匕首或潜伏姿态。
- **剪影／配色**：紫蓝短斗篷、浅金护甲边、双月刃与青紫反魔符文；轮廓轻且前倾，避免与 PA 的刺客剪影重合。
- **待机**：双月刃一高一低，前足探出，目光朝右；服装以轻甲和腰封为主，方便读取双刃与手部动作。
- **攻击**：右手月刃前切（ready），肩背蓄力（windup），双刃交错向右斩出（strike），左刃收回并恢复平衡（recovery）。
- **后续卡面方向**：破法、法力反制、闪烁残像。卡面不直接画数值或文字。

### 斧王（axe）

- **剪影／配色**：红铜重甲、暗灰皮革、宽肩与巨型单手战斧；主体厚重、低重心。
- **待机**：斧头垂落在身侧，披肩与腰带形成稳定三角。
- **攻击**：身体下沉（ready），斧头向后抡起（windup），从左后向右前横扫（strike），斧刃落下、重心回正（recovery）。
- **被动技能图集**：反击螺旋是独立于普攻的四帧循环。角色本体围绕竖轴原地转动，顺序为右侧、正面、背面、三分之四侧面；双手始终横握斧柄，披风、腿部和斧头随躯干转动。该循环不受“普攻一律右朝向”的限制，战斗层在被动触发时播放它，特效由外层另行叠加。
- **后续卡面方向**：承伤、反击、处决、逼战。卡面背景以赤铁和冲击裂纹为主。

### 虚空假面（faceless_void）

- **剪影／配色**：靛紫皮甲、青蓝时间裂纹、单手钉头锤；头部与肩甲有圆弧，区别于死灵法师的法袍。
- **待机**：锤柄斜指地面，另一手前伸，保持时间操控的克制感。
- **攻击**：锤子后撤（ready），身体压低并蓄势（windup），锤头从右上向右前砸出（strike），手腕回收、肩部复位（recovery）。
- **后续卡面方向**：时滞、停顿、追击、额外回合。卡面以破碎钟面和流动砂粒为主。

### 军团指挥官（legion_commander）

- **剪影／配色**：红金军团甲、深红短披风、长剑；正面军官姿态与大面积肩甲。
- **待机**：剑尖压低朝右，披风后扬，身体挺直。
- **攻击**：收剑于腰侧（ready），后脚蹬地并压低剑尖（windup），直线突刺后接短劈（strike），拔剑回守势（recovery）。
- **后续卡面方向**：决斗、战意、强驱散、单体压制。卡面采用军旗、剑痕、竞技场构图。

## 卡面风格规范（待机制确认后制作）

- 卡图采用无字方形插画，核心物体占画面 60% 以上；名称、星级、品质、流派标签由 UI 覆盖。
- 每个流派固定一组主色、边缘粒子和构图动势，双流派卡把两组色光交汇在同一主体上。
- 角色卡与通用流派卡分层：角色专属卡可露出该英雄局部轮廓；通用卡只画武器、符号或事件，不复用人物立绘。
- 先定四流派机制、命名与每流派卡数，再生成整套卡图，避免美术返工。

## 生成与验收

1. 先为每英雄生成透明背景待机立绘与四个攻击关键姿势；先审阅姿势、脚底落点、手持武器方向、人物比例。
2. 确认后输出图集与头像裁切，记录根点、攻击原点、武器握点到 manifest。
3. 将图集接入后，用实机检查左右镜像、武器长度、攻击命中时刻和高攻速循环。
4. 四流派设计定稿后，生成卡图；每批先出四张审阅，再批量完成。

## 边界与风险

- 本文不定义英雄技能数值、流派效果或装备数值；这些必须在内容设计中单独确认。
- 生成图保留透明背景，避免把战斗背景、光效、伤害数字和 UI 边框混入人物资产。
- 当前项目不是 Git 工作树，因此本规格无法提交；未来由用户初始化 GitHub/Gitee 仓库后可纳入首次提交。
