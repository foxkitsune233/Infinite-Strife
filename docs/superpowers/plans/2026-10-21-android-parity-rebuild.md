# Godot Android 0.1.5 复刻执行计划

此计划取代 `2026-10-21-mobile-015-parity-zh.md` 中“原创 6/6 简化构筑”的功能范围；旧文档保留作早期原型记录。

| 阶段 | 交付物 | 测试证据 |
| --- | --- | --- |
| P1 | `PreparationState`、`LoadoutPreset`、`LoadoutRules`、物品实例 | 保存、替换、切英雄、缺失清理、营地限制 |
| P2 | 竖屏整备页、英雄方案与仓库二级入口 | **完成首版**：配装／技能／物资分区切换，保存保持一级高频入口，合成与商店收进营地入口；仓库分类改为紧凑循环切换。 |
| P3 | 网格库存和物品操作 | **完成首版**：背包 4×3、安全箱 2×2、占位、旋转、锁定、整理、批量出售、快速出售、跨容器拖放与测试图标已接入；正式图标和移动端长按视觉反馈待美术迭代。 |
| P4 | 合成与商店 | **完成首版**：合成二级页按可合成优先显示，并清晰标示锁定／缺料；商店具备货架、金币购买、刷新版本号及陈旧报价拒绝。后续补入 Android 的事件优惠与难度货架。 |
| P5 | 远征与掉落 | **完成首版**：固定种子五节点、进入事件时冻结选项、掉落直接显示、逐件／一键放入背包及离开丢弃均已接入；暂时关闭无效的鉴定入口，避免阻塞收取。战斗节点当前以结算占位接入，待 P6 替换为真实战斗。 |
| P6 | 战斗规则对齐 | **完成首版**：远征普通战斗节点进入真实战斗并回传胜负；固定步长、蓝量、护盾、状态、冷却、主动装备与 60 秒结算已有实现。整备英雄、装备与卡牌会转换为战斗构筑；后续按 Android 完整数值表逐项校准。 |
| P7 | 存档和发布 | **进行中**：本地 JSON 存档已覆盖整备、背包格位、锁定、远征节点、事件冻结与地面掉落；支持当前版本往返及未来版本拒绝，首页可继续上次远征。待补：Android／iOS 导出与真机验收。 |

每阶段均先添加失败测试，再实现最小行为；不得用纯展示页面替代可保存的领域状态。
