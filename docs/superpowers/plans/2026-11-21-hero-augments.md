# 魔晶与神杖战斗接入

用户已授权继续补齐；依据Android的2026-10-22-017-open-hero-level-cap.md §2.5与M4交接清单，按既有十英雄效果接入，不重复设计或要求逐项确认。

1. 构建战斗时只读取已授予tower_shard/tower_aghs，待授予池不生效；标记进入fighter.hero_state以随战斗快照存档。
2. 魔晶：十英雄对应被动/常驻技能；破被动、免疫、驱散、反射及递归边界有测试。未定数值集中配置并注明Godot初始平衡值。
3. 神杖：十英雄单独主动，每场一次、无CD无蓝，活体且不受禁放控制才可用；失败不消耗资格。存档恢复不刷新使用资格，新战斗重新初始化。
4. 战斗新增神杖按钮，已授予才显示；英雄/塔页显示持有状态、具体强化说明，图标复用安卓shard/aghanim素材。强化事件复用现有技能/控制/受击反馈。
5. 分项测试、已有战斗与存档回归、实际渲染截图。保留原技能/装备手动操作和敌方自动流程。

分工：魔晶worker只改AndroidHeroRuntime及自身配置/测试；神杖worker新增独立HeroAghanimRuntime并扩展FighterState必要伤害机制；主代理负责构建标记、Engine命令、UI、集成、审查和验证。
