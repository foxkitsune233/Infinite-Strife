# 设置与状态/物品图标计划

用户批准制作设置页、状态图标和装备物品图标，音乐/音效音量搁置，音频可下载开源素材。

保持深蓝岩面、金色切角和扁平纸片风格。图标沿用现有代码矢量系统（ChestCrestView），绘制具象轮廓、局部色块和少量高光；装备家族通过形状、配色和组合区分，不依赖中文首字。卡牌继续使用30张已有卡面。

- [x] 设置：持久化动画开关、振动、正文大小、战斗记录、图标/文字状态摘要；默认保持当前行为。主界面统一设置入口，返回主页面重新应用设置。
- [x] 存档：使用Android系统文件选择器导出/恢复；恢复前完整校验与确认，正常save保留上一代备份；不新增存储权限，不实现清空存档。
- [x] 原生矢量图标：为实际目录中的装备、组件、卷轴、恢复品、材料、战利品映射明确图形，提供图鉴检视；卡牌保留卡面。接入格子、仓库、购买/合成详情、战斗主动槽。
- [x] 状态：从类型化StatusEntry生成图标、层数/剩余秒数，摘要横向滚动/可展开；禁止解析中文标签决定图标。
- [x] 音频：核对CC0官方来源，下载备用并保存许可证，不新增音量控件或伪造播放能力。
- [x] 外部验证：新增备份接口测试源码与手动测试表；主任务仅编译与打包，不执行测试或模拟器。
