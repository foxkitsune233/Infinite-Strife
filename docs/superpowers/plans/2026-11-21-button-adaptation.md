# 按钮适配修补

延续用户自主推进授权，保持原Android蓝金美术。先验收战斗主要操作与三页导航，避免对物品占格控件统一放大。

1. 增加720逻辑宽度下16:9、20:9、4:3竖屏，普通/最大字号的布局回归。以320宽缩放作为窄屏模型，主要按键至少48像素高；此为模拟缩放，不能宣称Android实际dp/真机验收。
2. 战斗技能、神杖、装备、结果按钮统一108逻辑高度；容器按真实最小高度从底部向上布局，HUD和舞台跟随避让。长按钮文字换行。
3. 底部导航同样增加高度；营地、远征、整备内容同步预留导航区域，避免增大后遮挡。
4. 检查鼠标/触屏事件和键盘焦点样式；确保禁用态可辨认，按下态和焦点不只依赖文字变化。
5. 跑布局、战斗、页面导航和样式回归。记录模拟范围与真机安全区尚未验收的边界。
