# 玩家界面与流程重建

目的：从程序入口齐全转为玩家能连续完成搜、打、换装、撤离。用户授权自主推进，不逐控件确认；保留Android美术、真实占格和六生效三备用规则。

布局：固定顶部当前阶段与返回入口；中间单一滚动内容区；固定底部当前阶段操作。营地提供远征、仓库、成长；远征提供当前路线、随身整备，不能把局外仓库当作远征物品来源。跨页保留远征节点与地面掉落，返回路线和放弃物品继续前进必须区分。

第一批：远征随身物品可选、拾取页直接装备、旧装备回包/背包满拒绝且不丢失、保存失败整体回滚、上下文导航说明。

后续：把路线/节点详情/拾取收纳拆成明确界面状态，进行返回栈和Android返回键处理；统一安全区、状态提示与详情抽屉，解决所有核心页遮挡。按营地→远征→战斗→拾取→即时换装→回路线→撤离全流程操作验收，另做手机真机验证。

本批完成不等于整套重建完成。完成前不凭单元测试宣称用户体验验收通过，不自动发新版安装包。
