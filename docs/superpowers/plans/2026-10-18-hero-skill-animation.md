# 六英雄简化技能表现

用户直接给出的动作方案为实施规格，继续使用现有Android View与透明角色素材。

- [x] 三张新增姿势：亚巴顿右手举剑；天怒左手主握、双手插杖；Viper头颈后收蓄力。内置imagegen生成，保留原素材不覆盖。
- [x] 引擎通过stepWithCues提供暂态语义事件；原step返回值和存档schema不变，不解析战斗中文日志，不增加随机调用。Journey层收集事件，保存成功后才交给View。
- [x] 主宰：无敌期间本体淡出，实际斩击事件在目标处画刀光与残影；结束复现。
- [x] 天怒：短暂双手插杖，六个真实flare tick分别触发敌方光柱；持续法阵不要求角色继续保持施法。
- [x] PA：criticalReady期间敌人头顶标记；真正消耗确保暴击且造成生命伤害时红色粒子喷溅；不增加本体施法动作。
- [x] 亚巴顿：施法举剑、强驱散脉冲、开盾壳和冲击；护盾持续显示由hero:aphotic实际剩余盾控制。
- [x] NEC：ghost期间绿色半透明和光环，冻结普攻动作；结束恢复。
- [x] Viper：蓄力帧短暂切换，再复用attack-v1完成吐毒，毒液轨迹与命中破坏符号。
- [x] 非持续动画按战斗tick推进，后台暂停不继续消耗动画；重进不重播瞬时事件；持续状态直接从存档快照恢复。动画不改伤害、耗蓝、冷却、控制与随机种子。
- [x] 编译与APK构建，交付外部测试表；主任务不运行测试、不启动模拟器。

解释：用户“NEC静止播放攻击动画”按幽魂护罩期间保持静止、停止普攻动作表现处理。原战斗规则已经禁止虚无状态普攻，不另设新规则。
