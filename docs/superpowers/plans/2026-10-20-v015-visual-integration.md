# 0.1.5 视觉资源接入计划

**目标：** 复用已审阅的 15 张卡面、24 张事件图、四名英雄攻击审阅图与斧王旋转图，导出有清单、可回溯、可预览的正式资源。

**结构：** 源图保留在 art-generation/art-source；导出器只做裁切、缩放、压缩和锚点注册。Android 根据稳定 ID 读取图片，事件图根据 artKey 读取；未发布的业务内容由外围任务实现。

- [x] 卡面：核对 15 个文件，导出 512×768 WebP，独立新清单，保持旧卡可读。
- [x] 事件：核对 24 个 artKey，导出 960×540 WebP；新增结果图加载 API 与未知 key 回退。
- [x] 英雄：复制原图，识别完整透明轮廓；统一 512×512 单帧、脚底根点 (256,464)，导出头像、普攻与斧王旋转图集。
- [x] 动画：兼容现有 AttackAtlas，提供新英雄图集；军团/斧王污染帧及旋转末帧经百炼单独补绘。
- [x] 预览：导出卡面/事件联系表和角色动作 GIF，逐图检查。
- [x] 校验：图片存在性、尺寸、透明通道、清单覆盖、Android 编译；设备检查步骤已写入 `docs/testing/59-v015-visual-integration.md`。

用户已授权全部开始实施；本批不调整战斗公式、数值、内容投放或版本号，不覆盖 0.1.4 发布包。
