# 剧情功能迁移实施计划

目标：导入已写文本，任务领奖可播放立绘对话、结局可播放黑幕字幕；不改变奖励和英雄可用性。

采用数据JSON + StoryCatalog + StoryRules + 全屏StoryPlayer。队列、当前页和已读写入现有quest_progress.story，不增加不兼容存档版本。领奖先奖励与排队一起保存，再播放；关闭/跳过才标已读，播放失败/保存失败不吞剧情。旧档任务可回顾，不集中补弹。

1. 并行子代理仅负责导出器与story.json；主代理负责规则与UI，避免共享文件写入。
2. 先写测试验证目录、队列去重、翻页恢复、领奖失败回滚、末页/跳过。
3. 实现左右原图、发言高亮、营地背景与蓝金文本面板；黑幕字幕渐显和长文本滚动。
4. 挂接领奖、选英雄与待播恢复，提供可用剧情回顾；塔剧情提供接口，待真实塔结算提交后挂接，结局预览明确区别于通关。
5. 跑Godot测试并检查实际渲染，记录未完成差异。
