# 成长页显示修补

用户截图暴露了默认小字号和材料字典直出的旧页面。ProgressionScreen原按钮没有使用AppSettings字号，材料使用str(Dictionary)，任务物品奖励也显示英文ID。

- 成长材料和物品奖励读取Android物品目录的中文名，例如背包织件×2、安全箱锁芯×1；不足提示也翻译同一材料名称。没有修改材料需求、花费或成长条件。
- 标题、任务文字、状态和按钮使用可缩放字号；主要按钮最小高度108逻辑单位。材料可换行，关闭横向滚动。
- 返回主页、剧情回顾在固定底部并排，滚动区位于其上；长列表末项可完整滚入视口。
- 普通/最大字号及720×960、720×1280、720×1600逻辑视口专项438检查，0失败。7项相关回归通过，最后提示调整后4项复跑退出0，无脚本错误或断言失败。本轮没有重跑全项目全部测试。
- 实际OpenGL截图tasks-0/growth-0和tasks-2/growth-2已检查，捕获脚本结束恢复原偏好。未做Android真机、密度或安全区验收。
