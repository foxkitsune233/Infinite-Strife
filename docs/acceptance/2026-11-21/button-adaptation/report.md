# 主要按钮适配验收

本轮覆盖战斗技能、神杖、六格装备、结果按钮及三核心页底部导航。保持原蓝金主题与Android美术；没有改变仓库真实占格规则。

- 主要触控区域提高到108逻辑高度。720逻辑宽缩放到320宽时为48像素；此为桌面等比缩放模型，不能当成已验证的Android dp。
- 战斗操作区由内容最小高度决定，固定在底部；HUD和舞台避让。较矮竖屏技能/神杖并排，长屏纵排。换行、显隐、结果按钮出现及实时缩放都会触发重排。
- 底部导航同步增加预留区与字号。整备矮屏缩小留白、调整仓库滚动区，技能/物资模式及展开工具后重算高度。
- 绘制状态区分普通、悬停、按下、禁用和键盘焦点；共享主题中的未单独着色按钮也有反馈。

验证：test_button_adaptation 在720×1280、720×1600、720×960逻辑视口，普通/最大字号下完成294项检查，0失败。包含按钮宽高、边界、互不重叠、导航避让、实际三页面、整备模式/工具、窗口缩小和恢复、释放过期布局高度。全量97项测试退出码0，未出现脚本错误/断言失败；审查与视觉调整后复跑相关10项及最终战斗/UI4项均通过。

真实OpenGL截图：battle-1280.png、battle-1600.png、battle-960.png、preparation-960.png；capture_button_adaptation.gd使用独立会话并恢复原偏好。

限制：未覆盖所有弹窗与所有辅助页按键尺寸，也未进行Android真机、密度、刘海/挖孔和系统手势安全区验收；本轮不能声明全项目全部设备适配完成。已有音频播放对象退出泄漏警告仍会间歇出现在战斗测试中。Windows导出按用户要求继续搁置。
