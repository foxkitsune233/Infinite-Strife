# 魔晶与神杖战斗验收

依据 Android 2026-10-22 英雄等级上限设计 §2.5 与 M4 交接清单，补齐十位英雄的魔晶被动与神杖主动。此处对齐既定设计，不能称为 Android 已实现战斗代码的逐值复刻；未明确的数值为 Godot 初始平衡值。

- 构建只读取已授予英雄；待授予池无效果。新战斗重置，快照恢复保留计时、随机状态与已消耗资格。
- 神杖每场一次，无魔耗/CD，控制和死亡门控，拒绝施放不消耗。手动施放存档失败会回滚战斗、资格与流程快照。
- 已接十英雄魔晶；具体数值集中在 HeroShardConfig。天怒指数耗蓝10点起逐秒翻倍，最多20秒；敌法师额外15%乘算魔法/生命扣除减伤。
- 已接十英雄神杖；详情见 HeroAghanimRuntime.description。面板显示授予效果，战斗显示持有/已使用、原版神杖图标、技能名称、反射反馈及持续状态。
- 修复通用技能伤害与控制分离反射、反射击杀未结算、DOT误耗反射资格、虚空历史采样早于同刻攻击和无初始采样。
- 最大字号下，HUD按实际高度重新定位并同步收缩舞台，保持在操作区上方。两张真实 OpenGL 截图由 capture_hero_augments.gd 生成；沿用Android贴图。脚本使用独立存档，结束恢复原设置。
- 截图同时发现远征敌人自定义ID被特效层误当成左侧；已按实际右侧战斗ID绑定特效锚点，并新增覆盖。最终4项受影响UI/特效回归退出码0。

Godot 4.7.1 全量96项：退出码均0，未出现脚本错误/断言失败。最后反馈/UI调整后复跑六项受影响测试。反射边界专项29检查0失败；覆盖各英雄效果、控制、重复施放、授予归属、JSON续战、存档回滚与大字号边界。

已知限制：战斗UI测试退出仍有一个 AudioStreamGeneratorPlayback 的 ObjectDB 泄漏警告（verbose已定位），未解决；不能把零断言失败描述为零警告。未做Android真机和导出包验收，Windows打包继续搁置。原合成页测试依赖起始测试材料，已改为显式提供余烬矿和树枝，验证可合成优先排序。
