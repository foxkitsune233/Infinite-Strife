## 自动化

```powershell
.\gradlew.bat --offline testDebugUnitTest --tests '*ProfileBackupTest' --tests '*UiIconCatalogTest'
.\gradlew.bat --offline testDebugUnitTest assembleDebug :shared:compileKotlinJs
```

新增测试源码：ProfileBackupTest 6例；UiIconCatalogTest 4例。

| ID | 自动断言 |
|---|---|
| B01 | 导出/只读检查可往返，检查不改当前文件 |
| B02 | 校验和损坏被拒绝，当前存档字节不变 |
| B03 | 重新算对CRC但金币非法的文件被业务校验拒绝 |
| B04 | 未来版本被拒绝，当前存档不被替换 |
| B05 | 超过限长及截断的备份被拒绝 |

| I01 | EquipmentCatalog所有装备/组件/卷轴有明确图标映射 |
| I02 | 初始属性装备、药品与成长材料有明确映射 |

## Android设备

使用320/360/411dp宽度、系统字体1.0及1.5倍，各设置文字等级；先保留现有真实存档的备份。

| ID | 操作 | 预期 |
|---|---|---|
| S01 | 营地/远征/整备打开设置并返回 | 头部一按可达；返回原页面与进度 |
| S02 | 改动画/振动/日志/状态摘要，重启应用 | 偏好保留，游戏金币、物品、随机种子不因改设置变化 |
| S03 | 关动画后进入多英雄战斗 | 不播放瞬时技能/普攻姿势；保留静态状态与HUD；打开恢复，系统禁止动画时应用不能强制开启 |
| S04 | 关振动后按按钮、长按拖动 | 两处都不发起触感反馈；开启仍服从系统振动偏好 |
| S05 | 切换文字大小并返回各页面 | GameUi正文/按钮与背包标签应用倍率，不改变格子位置；长名称可通过详情读取 |
| S06 | 关闭战斗记录再进入战斗 | 不显示最近事件区域；引擎日志和结算不受影响 |
| S07 | 图标摘要/文字摘要来回切换 | 均可查看全部状态，层数/秒数与真实快照一致，不重播施法 |
| S08 | 普通毒、剧毒、眩晕、破坏、免疫等大量并存 | 图标横向滚动，不截断总种类；毒滴/孢核区分；点图标可展开完整文本 |
| S09 | 状态秒数随战斗更新/驱散/结束 | 数值刷新，消失状态移除，不残留旧图标；按相同key复用控件 |
| S10 | 图鉴逐项查看装备/材料/卷轴 | 对应名称、品质、占格正确；三双刀配色、BKB黑柄、卷轴产物小图可辨识 |
| S11 | 装备/技能/背包/安全箱/仓库 | 非卡牌显示矢量图，卡牌保留原卡面；药品数量/绑定标记可见，不改变拖放命中区 |
| S12 | 宝箱reveal=0/1/2分别查看 | 未完全公开不出现具体物品图标，详情和无障碍文本也不泄密 |
| S13 | 商店/合成列表、购买/合成详情 | 图标对应实际产物；无珍品占位不能当商品购买；列表顺序对应业务对象 |
| S14 | 6件主动装备同时显示 | 每槽有图标、名称、CD与独立模式操作，字号大时仍可触达，底部导航未被覆盖 |
| S15 | 导出备份，取消文件选择，再导出成功 | 取消不写存档；成功文件可通过B01接口读取，无需存储权限 |
| S16 | 导入坏文件/超大文件/未来版本/取消 | 明确报错或取消；原存档、金币、物品不变 |
| S17 | 选择合法旧备份，先取消确认再确认恢复 | 取消无变化；确认后恢复该备份真实物资和挑战进度；当前有效代留作上一代备份 |
| S18 | 在整备打开设置恢复旧档，返回后移动一件物品 | 整备已重读恢复后状态，不会把原内存中金币/物品写回覆盖 |
| S19 | 战斗中打开设置，导出/恢复后返回 | 挑战暂停；返回从恢复后的真实阶段继续，不能重复结算或重播旧技能 |
| S20 | 主档和上一代均损坏，尝试恢复外部备份 | 原保护机制允许拒绝覆盖，说明失败并保留原文件，不偷偷授予初始物资 |
| S21 | 恢复默认设置 | 只改显示偏好，游戏存档不变 |
| S22 | TalkBack浏览图标、切换器和选择器 | 有可读名称；状态图标可聚焦并展开；不能只靠颜色识别 |
| S23 | 查看素材来源 | 说明Kenney CC0备用音频；没有音量滑块，没有声称已播放或已有完整背景音乐 |

## 交付边界

- 图标为Android原生矢量首版，41种基础轮廓+家族变体；105个非卡牌ID已静态核对映射，最终辨识度需S10视觉验收。
- 音频下载于art-source/audio，保留ZIP及原许可证，尚未纳入播放器或APK；85段短乐不是完整循环BGM。
- 本轮仅使用文件选择器授予的URI，不自动上传存档，不接网络账号或同步服务。
