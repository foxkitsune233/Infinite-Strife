# 51 装备／卡牌拖入占用槽自动替换

当前对应版本：0.1.3-19A1-44B2-E23F，内部构建1006，存档继续v11。原误标0.1.5-CFD4-9A87-D795的替换功能已归入0.1.3，旧包只保留取证。主任务只编译测试源码，设备及单测外部执行。

## 替换去向

| 拖入来源 | 旧物去向 |
|---|---|
| 局外仓库 | 返回仓库 |
| 另一个装备／技能槽 | 与来源槽互换；包括装备生效区／备用区 |
| 背包或安全箱 | 尝试原位置，允许旋转；否则尝试普通背包，不自动挪进安全箱 |
| 当前待拾取区 | 旧物回待拾取区，可以再次替换取回 |

若旧物无法安置，两物都保持原状。类型、锁格、战斗阶段照常校验。绑定、星级、数量、实例ID不变；不加新费用。背包／安全箱的占用格不支持这种覆盖。
