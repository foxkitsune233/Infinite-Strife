# 64：版本日志外部验收表

范围：版本日志首次弹出、语义版本去重、设置页回看。当前应用包的版本名格式为
`0.1.x-XXXX-XXXX-XXXX`；版本日志只比较前面的 `0.1.x`，后三组构建索引不参与已读判断。

## 前置条件

1. 安装含版本日志的调试包或后续 0.1.5 包。
2. 本表中的“清除体验设置”只影响 `presentation-settings-v1`，不应删除战役存档。
3. 当前包版本为 `V`，例如 `0.1.5-B5E7-3C9A-71F4` 时，语义版本为 `0.1.5`。

## 设备验收

| ID | 操作 | 预期 |
|---|---|---|
| VL01 | 清除应用“存储空间”中的体验设置后启动应用，进入营地。 | 营地内容先正常加载，然后自动出现“版本更新”页；不遮挡崩溃提示或存档恢复提示。 |
| VL02 | 查看首次“版本更新”页。 | 显示从 `0.1.3` 开始的日志，按新到旧排序；当前版本卡片有高亮；当前 `0.1.5` 包显示 `0.1.5`、`0.1.4` 与 `0.1.3`。 |
| VL03 | 关闭版本更新，退出应用并再次启动。 | 同一语义版本不再次自动弹出。 |
| VL04 | 打开设置 → “图鉴与来源” → “查看版本日志”。 | 始终可打开完整可见历史；标题为“版本日志”，关闭后返回设置。 |
| VL05 | 在相同 `0.1.x`、仅后三组构建索引不同的两个包之间覆盖安装。 | 第二个包首次进入营地不重复弹版本更新。 |
| VL06 | 从 `0.1.4-…` 覆盖安装到 `0.1.5-…`，进入营地。 | 自动弹出一次；日志显示 `0.1.5`、`0.1.4`、`0.1.3`，且 `0.1.5` 高亮。 |
| VL07 | 进入设置 → “恢复默认体验设置”，确认后返回营地。 | 游戏存档、金币、物品与远征进度不变；下次进入营地会再次显示当前版本更新，因为体验设置中的已读标记被重置。 |
| VL08 | 设置页反复打开、关闭“查看版本日志”，并旋转屏幕或切换后台后返回。 | 不崩溃、不重复叠加多个弹窗；文字可滚动且无截断。 |
| VL09 | 当前版本名为空或读取失败的测试包。 | 不自动弹出；设置页手动打开仍可安全显示可用历史或空状态，不崩溃。 |
| VL10 | 系统字体调到 1.3，使用 320dp 宽度设备打开首次更新页和设置入口。 | 标题、版本号和每条说明不重叠；内容可纵向滚动；关闭按钮可触达。 |

## 数据核对

| 版本 | 应出现的主题 |
|---|---|
| 0.1.3 | 五战远征、宝箱鉴定、整理/安全箱、六名首发英雄、合成和基础战斗。 |
| 0.1.4 | 节点掉落拾取、本局金币、鉴定演出、配装保存、锁定/出售、UI 统一。 |
| 0.1.5 | 四名新英雄、怒火/寒霜、流派装备与事件、六档挑战和敌方预览。 |

## 自动化建议

该功能使用 Android `SharedPreferences`，适合用 Robolectric 或设备 UI 自动化覆盖以下最小断言：

1. 给 `presentation-settings-v1` 写入与当前语义版本相同的 `lastSeenRelease` 后，`showIfUnread` 不创建弹窗。
2. 写入旧版本后，`showIfUnread` 创建一次弹窗并把 `lastSeenRelease` 更新为当前语义版本。
3. 包版本 `0.1.4-AAAA-BBBB-CCCC` 与 `0.1.4-DDDD-EEEE-FFFF` 归一化为同一已读键。
4. `0.1.10` 排在 `0.1.9` 后，避免字符串字典序导致未来版本过滤错误。

本表为外部验收文档；设备项（VL01–VL02、VL05–VL10）按 Debug 夹具由外部执行，本轮已用离线单测覆盖自动化 3/4。

## Debug 夹具

调试包中打开“设置 → 存档与诊断 → 通用测试模式”即可使用。该页新增的版本日志
夹具只写 `presentation-settings-v1` 的 `lastSeenRelease`，不会激活、重置或覆盖正式/测试战役存档。

| 控件 | 用途 | 对应项 |
|---|---|---|
| 清除版本日志已读标记 | 模拟首次进入前状态；返回游戏后由正常入口决定是否弹出。 | VL01、VL03、VL07 |
| 模拟 0.1.3 / 0.1.4 / 0.1.5 首次进入 | 不用重装不同版本包，直接预览指定语义版本的首次弹窗并写入该版本已读标记。重复点击应提示已读且不再开新弹窗。 | VL02、VL03、VL06 |
| 模拟空版本日志 | 验证无匹配版本时不会创建首次弹窗，手动预览显示空状态。 | VL09 |
| 预览当前版本日志 | 不写已读标记，便于反复检查文案与小屏布局。 | VL04、VL08、VL10 |
| 打开设置中的版本日志入口 | 从夹具直接跳转正式设置入口，核对关闭返回路径。 | VL04 |

自动化 3/4 可直接测试 `VersionLog.semanticVersion` 和 `VersionLog.notAfter`；两者为
`internal` 纯逻辑入口，不改变生产行为。

## 外部复验执行记录

自动化 3/4 与 VL02/VL09 的数据核对已用离线单测覆盖，用例放在
`app/src/test/java/com/example/douqiuqiu/ui/VersionLogTest.kt`。

| 项 | 自动化方法 | 结果 |
|---|---|---|
| 自动化 3 | `semanticVersionIgnoresBuildIndex` | PASS：`0.1.4-AAAA-BBBB-CCCC` 与 `0.1.4-DDDD-EEEE-FFFF` 均归一化为 `0.1.4`，同一已读键。 |
| 自动化 4 | `notAfterComparesNumericallySoTenFollowsNine` | PASS：`0.1.10` 排在 `0.1.9` 之后，避免字符串字典序误判。 |
| VL02 / VL09 | `visibleHistoryExcludesFutureVersions` | PASS：历史只含不超过当前语义版本的条目，未来版本不显示。 |

> 设备项（VL01、VL03、VL04–VL10）仍由外部按 Debug 夹具执行；其中 VL01/VL03/VL07 的“清除已读标记”、VL02/VL03/VL06 的“模拟各版本首次进入”、VL04/VL08/VL10 的“预览当前日志”与“跳转设置入口”均已具备夹具入口。
