# 八种事件接线与首轮结算值

以下为 `JourneyEvents` 首轮内容基线；界面只展示风险类别和致死提示，不展示概率或精确伤害。数值未经过平衡验证。

所有金币代价取节点生成时保存的 `20 + 回合 × 10 + 难度 × 10`，仅扣本局金币。每个节点的种类、roll、所需材料和价格生成一次后存档；物品池按定义 ID 排序，结果由已保存 roll 决定，不读取时钟或全局随机数。

| 事件 | 首轮隐藏结算 |
| --- | --- |
| 废弃补给站 | 搜索 70% 药品，其余扣最大生命 10%；可离开 |
| 锈蚀工坊 | 强拆 60% 基础组件，其余扣最大生命 12%；付费必得组件；可离开 |
| 残破书库 | 深入得一星卡，40% 同时扣最大生命 15%（中毒当场结算）；大招羁绊生效时安全研读得卡；可离开 |
| 坍塌仓室 | 左路必扣最大生命 10%，60% 额外得通用材料；右路交本局金币安全通过 |
| 保险库残骸 | 搬走已解锁的锁芯/框架，或拆解得通用材料，或放弃；锁芯至少一次通关，框架至少五次通关且背包高至少三格 |
| 技术终端 | 玩家选交一份残存精华，换一份已解锁技能刻片；冒险操作 50% 得刻片，否则扣最大生命 15%；可离开 |
| 临时医棚 | 交本局金币恢复最大生命 25%；玩家选交一份药品恢复 40%；可离开 |
| 拦路者 | 交本局金币或选交一件物品；强闯 60% 扣最大生命 10%，其余扣 25% |

交付只接受玩家明确选择的局内实例。安全箱物品需要 `allowSafeContainer=true`，仓库物品一律不能交付。堆叠药品只消耗一份。发奖只进背包，继承定义绑定属性；容量不足返回原始状态，金币、材料、生命、事件结果全部不变，整理后重试仍是同一结果。缺少奖励定义的模板不生成，静态选项遇到进度不满足时明确拒绝，不替换成其他随机奖励。

非致死成功进入下一回合 READY；致死结果返回生命零及已结算节点，由 JourneyRules 立即调用现有失败结算。结果实例使用 `runId:event:round:index`，供材料带出保底识别。

新增 `JourneyEventsIntegrationTest` 覆盖八模板可结算、局内金币、重复领取、明确选物、安全箱授权、堆叠数量、仓库隔离、容量失败原子性、整理重试、致死提示、生成稳定性、缺少定义、进度和羁绊条件。本次编写时未执行测试，编译和统一验证由主集成流程完成。
