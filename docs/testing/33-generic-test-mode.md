# 通用测试模式与外部验收表

2026-10-18。目标：直接进入指定事件、奖励、休息、战斗或营地场景，减少反复刷关。已在 Pixel36（Android 16 / API 36）实机执行 S01–S12，结果见下表。

## 入口与隔离

调试包：设置→存档与诊断→通用测试模式。顶部始终显示“测试存档”。正式Release没有该Activity和入口。

- 正式文件：`profile/inventory-v1.dat`；测试文件：`profile/test-inventory-v1.dat`，两者各有独立备份。
- 鉴定收据、隔离记录、战斗日志、最近异常也分开保存。显示/音效偏好仍为全局设置。
- 载入场景仅重置测试存档，重建Activity任务栈，防止旧页面继续持有另一模式的Repository。
- 退出测试模式后重新打开正式存档；这不是把测试金币、物资或通关次数导入正式存档。
- 模式选择跨重启保留；再次进入设置可以退出。已有正式鉴定必须先按原规则完成，不能用测试模式跳过。

每次新建夹具有独立attempt标识。可“重复上次场景”，复制配置JSON，或粘贴其他测试者的JSON复现。战斗导出ZIP附当前场景配置；JSONL同时标记sandbox、场景和attempt。

### 重要边界

- 奖励场景是人为构造的合法胜利快照，不证明真实战斗能赢；要验战斗→奖励完整链，选直接战斗＋弱敌。
- 事件夹具使用模型已支持的固定roll快照，后续由真实事件结算器处理；不绕过条件、交物确认或容量检查。
- 仓库预置多份物品，验“唯一发放”应核对领取前后增量及实例ID，而不是要求某定义总数等于1。
- 商店时钟仍为现实时间。首版没有虚拟时钟、磁盘故障注入、任意战斗属性编辑或自动断言，这些不应标作完成。
- 测试配置中的控制/弱敌只作用于指定直接战斗；不传播给后续自然敌人和正式英雄内容。

## N06快速操作

1. 场景选“战后奖励”，第5战，生命50%，固定种子1729、本局金币999，载入。
2. 选择回血，核对目标箱各实例只增加一份，鉴定不可跳过，金币带出正确。
3. 重复上次场景，分别选择金币和物品；每次起点相同。该固定目标难度0，第5战金币奖励70，本局金币应从999增至1069后带出；其他分支仍带出999。
4. 导出测试记录并保留配置、APK指纹及截图；退出模式核对正式存档未变。
