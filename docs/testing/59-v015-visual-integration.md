## 与外围代码的接口

### 英雄

资源ID为 `antimage` / `axe` / `faceless_void` / `legion_commander`；兼容 `anti_mage` 作为敌法师别名。

- `GameArt.hero/pose`：新英雄待机资源。
- `GameArt.portrait`：新英雄头像，整备与出发选择已调用。
- `AttackAtlas`：合并读取 `art/heroes/v0.1.5/attack-manifest.json`，只采用 `runtimeReady=true` 条目。
- 四英雄大招使用现有 `ULTIMATE_CAST` cue，其 `heroId/actor/target/tick` 必须来自实际结算。
- 斧王被动需要追加稳定机器cue名 `COUNTER_HELIX`（actor=斧王，target=敌方），480ms四帧本体旋转已接好。视觉层不按受击次数自行推算。
- 持续时停读取 `Fighter.timedControls` 中机器名 `TIME_STOP` 且 `remainingMs>0` 的条目；控制结束或读档后由同一快照决定染色。

本批没有修改shared技能、角色投放或状态结算。当前shared仍为旧六英雄；新增角色必须由外围内容代码投入后才能在普通游戏中选择。
