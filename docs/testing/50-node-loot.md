# 50 节点掉落、鉴定与携入资金（外部验收）

当前对应版本：0.1.3-19A1-44B2-E23F，内部构建1006，存档v11。原误标0.1.4的节点掉落、0.1.5的替换修改均归入0.1.3，旧包只保留取证。所有运行用例尚未由主任务执行，不能引用旧782项通过记录作为本次验收。

## 定案与本轮实现

- 完全取消战后三选一：每次胜利直接发本局金币并冻结物品掉落。金币沿用同难度/战次现有数值，不回血。
- 普通战斗1～3件、第五战3～5件；有物品收益的事件2～6件。事件第一份保留该选项的主题/进度材料，其余可为任意类型品质，按进度、品质/价格权重抽取。此为首轮配置，未完成平衡采样。
- 物品收益事件另给同战次金币奖励的一半（向下取整）；付费/交物/伤害仍按原事件结算。失败/离开/纯治疗事件不凭空追加战利品。
- 入场可指定携入金额：营地钱包原子扣“门票+携入资金”，runGold增加携入资金。金额不可负、不可超余额；入场确认及按钮显示总扣款。
- 掉落先不归玩家、不占容器、不提供效果；鉴定后拖到合法容器才获得。无障碍保留点按预览→手动选格，仍由相同拾取事务校验，不自动塞包。
- 待拾取区可接收已拾取和带入物品；可在当前节点内放下再取回。已知物不重复鉴定；星级、绑定和剩余数量保留。放下期间无装备效果/安全箱保护。
- 事件先800ms开箱，然后沿用AppraisalTiming按占格、品质、固定价值计时（最多3件并行）；战斗掉落直接鉴定。不能跳过；后台/失焦暂停，鉴定进度和物品来源写入存档。
- 离开需要鉴定完毕；剩余物品必须确认丢弃。事件拾取后进入下一战READY；第一/二/四战拾取后进事件；第三战进REST；第五战通关并将目标箱直接入库。
- 冻结掉落列表、picked和putDown分开保存。重进不重抽、不重复给金币；未拾取/放在地上的物品不计入撤离/死亡带出与材料保底。
