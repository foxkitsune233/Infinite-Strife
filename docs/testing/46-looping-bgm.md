# 46号：循环背景音乐

用户要求先解决BGM，界面讨论延后。本批不改界面布局与玩法。

## 已接入

- TAD / Once Upon a Time (loop)，原作者页面标注CC0 1.0：<https://opengameart.org/content/once-upon-a-time-loop>。
- 原WAV保存在`art-source/audio/once-upon-a-time/`，原页面快照与出处保留；包内`audio/bgm.ogg`，Vorbis 44100Hz双声道，57.595397秒，约1MB。
- 不裁切/重排原循环；播放器isLooping=true。先使用单曲低音量贯穿营地/整备/战斗，不频繁换曲或重播。
- 音乐独立开关，默认开启，不跟随“游戏音效”开关；无音量滑条，服从系统媒体音量。恢复默认设置会同步开启音乐。
- Application注册唯一生命周期播放器，异步准备，不在主线程同步解码。切换应用内Activity短暂衔接180ms，后台暂停且放弃音频焦点，返回从原位置续播；进程被杀后重新启动从曲首播放。
- 收到暂时音频焦点丢失暂停，恢复后在前台且开关开启时继续；duck时降低音量；永久丢失暂停，不立即抢回焦点。
- 素材或解码失败只记录GameMusic日志，不阻塞存档或游戏。
- 署名：设置→制作与素材来源；包内`audio/bgm-credits.txt`。
