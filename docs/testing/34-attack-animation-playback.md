# 角色动作播放修正（外部验收）

依据：用户反馈只见特效、不见人物攻击。四帧图集已有不同姿势，本轮不重新生成原画。

## 代码发现与改动

- 旧播放门控同时检查游戏开关和Android系统动画倍率。系统倍率为0会停用角色帧、部分提示型动作，但状态特效仍可能显示；尚未读取本次设备设置，不能断言这是该设备唯一原因。
- 战斗动作改为只由游戏内“技能与普攻动画”控制。游戏设置关闭时仍保留静态角色，不自动覆盖用户偏好。
- 角色挥击用独立显示时钟，动画期间可继续刷新，不再受每个模拟tick的100ms插值窗口限制。
- 高攻速下可见挥击至少180ms，正在进行的挥击不被每次命中反复重置；命中/伤害事件不合并、不减次数，战斗计算和RNG不变。
- 调试场景的种子、场号、roll、金币、血量及控制参数补中文校验原因。
