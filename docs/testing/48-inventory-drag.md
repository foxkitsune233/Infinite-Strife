# 48 仓库拖放专项（外部执行）

本轮针对“拖不起来／松手不入槽”和“整个武器栏高亮”。设备测试未执行，以下均待验。47号整体布局表继续适用；进入仓库闪退尚未取得对应设备堆栈，本轮不声称已修复闪退。

## 实现范围

- 仓库图标静止按住250ms启动原生拖放；先滑动超过系统touchSlop仍滚动列表，不强行劫持滚动。
- 起拖前锁住父层触摸拦截；调用失败提示，不在松手后误开预览。普通点按仍打开二级预览。
- 拖影抬到手指上方，下方小指针表示真实落点；不是用漂浮插画的位置判定落点。
- 仅当前目标格绿／红高亮，不同时点亮所有合法格或整个装备栏。切换到相邻格时目标随动。
- 槽位左右外缘12dp容错仍限制在该Board内；不跨占用槽自动找另一个格，不覆盖旧物品。
- 拒绝时显示原规则原因；松在无目标区时提示未放置，保留原物品。
- 悬停校验仅落点格改变时求值，绘制不再每帧完整验证存档。
