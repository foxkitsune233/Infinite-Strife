# 56：0.1.4 UI 外部验收表

本表仅记录设备验收，不以编译或历史测试替代实际触控确认。

| ID | 场景 | 操作 | 预期 |
|---|---|---|---|
| U01 | 营地首页 | 冷启动普通存档 | 首屏只见远征主行动、紧凑统计、整备与更多；无长段规则堆叠。 |
| U02 | 营地二级页 | 点“更多” | 只出现“探索”“鉴定”两区；图鉴和规则不再占首页。 |
| U03 | 宝箱二级详情 | 打开选箱列表，点击白/蓝/紫/金箱，再返回 | 列表只显示箱体、主题、容量与票价；点击后进入独立详情页，显示真实物品格阵、已知线索、随机鉴定、目标管理与进入挑战。列表不内嵌格阵。详情格数按实际容量变化；返回键回到选箱列表。 |
| U04 | 整备顶部 | 打开整备，选配装 | 头像、三个方案、9格装备栏位于顶部；六生效格与三备用格可辨；顶部不挤压下方仓库。 |
| U05 | 技能 | 点技能页签 | 技能栏最高八格可访问；切回配装和物资后状态不丢失。 |
| U06 | 背包尺寸 | 物资页切背包/安全箱 | 两种容器单独显示，格子尺度一致；旋转、拖影和落点尺寸一致。 |
| U07 | 掉落页 | 战后进入搜刮 | 上方显示背包/安全箱，下方始终显示地面掉落；不再要求在“待拾取/随身物品”之间切换。 |
| U08 | 拖放 | 长按地面物品，拖到背包可放位置 | 仅合法目标格高亮绿框；松手后进入背包。非法位置显示明确失败反馈且原物仍在。 |
| U09 | 占用替换 | 将装备/卡牌拖到兼容的已占栏位 | 只高亮目标单格，显示替换提示；成功后旧物按规则回到来源。 |
| U10 | 鉴定 | 宝箱和掉落分别触发鉴定 | 均使用石板/轮廓/进度表现；不能跳过，未知物品不提前显示名称。 |
| U11 | 小屏 | 320dp 宽度、系统字体1.3 | 主行动、返回远征、整备页签均可点；文字不覆盖主操作。 |
