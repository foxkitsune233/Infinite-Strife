# 吸血、恢复、增伤与状态抗性

2026-10-16。用户明确：吸血、恢复作用范围、恢复叠加、状态抗性套用 Dota 2；中毒属于法术伤害，适用法术增伤叠加策略。本文件覆盖此前相关待审与简化选项；是机制规格，不表示战斗代码已经实现。

## 参考口径

以本日核对的 Liquipedia 机制页及其 7.41 恢复改动记录为参考快照，不随未来原作更新自动改本游戏。机制页仍有旧分类文字，以明确版本变更优先；不继续套用 7.39 时“恢复增强不影响直接治疗”的旧口径。

采用的是叠加与作用机制，不自动更换本游戏已定英雄、装备属性、持续时间、CD或合成范围。护盾伤害50%折算攻击吸血、同名卡叠加、唯一组、生命移除及反伤排除仍按本游戏已定规则。

## 1. 普通攻击吸血

- 普通百分比攻击吸血相加；同名普通吸血装备的多个生效实例也加入合计，不凭空加“同名唯一”。主动状态不因携带多件而重复叠加，同组主动沿用共享CD与刷新规则。
- 攻击吸血和法术吸血是不同属性；有法术伤害不代表自动具有法术吸血。D5毒血回流是卡牌明确授予的限定恢复，不与普通攻击吸血混用。
- 本游戏攻击吸血基础值 =（实际扣除生命的合格攻击伤害 + 同次攻击被盾吸收的伤害×0.5）×吸血率合计。之后进入恢复增幅计算。过量击杀、反伤、自损、生命移除和无效攻击不计入。

依据：[Lifesteal](https://liquipedia.net/dota2/Lifesteal)、[Satanic](https://liquipedia.net/dota2/Satanic)。

## 2. 恢复分类与叠加

生命恢复增强影响持续回血、直接治疗、攻击/法术吸血和恢复生命的道具；不因此增强护盾、回蓝、最大生命换装调整、生命设值或复活。魔法恢复与补充为独立属性；NEC幽魂护罩按技能自身同时授予生命和魔法相关恢复增幅，不能由“普通生命恢复增强”推导出回蓝增强。

百分比先转小数、先处理唯一组。散华及其升级的恢复增幅取最高；慧光家族回蓝增幅仍按已定家族取最高。普通恢复率或治疗基础量不是“恢复增强”，不要合并到同一加成池。

生命恢复的增幅和抑制分别递减叠加，再相减：

```text
A = 1 - Π(1 - 每个有效恢复增幅)
R = 1 - Π(1 - 每个有效恢复抑制)
恢复倍率 = 1 + clamp(A - R, -1, 1)
```

例如两个独立20%增幅先合为36%，再受到30%恢复抑制，最终倍率1.06；基础恢复100变为106，不是98或100.8。生命不因恢复倍率小于零而反向受伤，实际恢复不超过缺失生命。

7.41口径：受到治疗增强与生命恢复增强递减合并，而非与施加治疗增强相加。施加治疗增强保持施法者侧独立计算，只对直接治疗生效；不能把同一增幅同时投入两侧重复算。魔法恢复/补充按对应属性相加，按来源资格应用；不套用上述生命恢复递减公式。首版不引入未配置的独立回血专用增幅。

依据：[Restoration Manipulation](https://liquipedia.net/dota2/Restoration_Manipulation) 的公式与7.41变更、[Necrophos](https://liquipedia.net/dota2/Necrophos) 的幽魂护罩分类；[官方7.41a更新](https://www.dota2.com/news/updates/16749/)也记录了受到治疗增强与生命恢复叠加的修复。

## 3. 法术伤害与中毒

2026-10-17毒系重做补充：以下毒伤计算用于普通毒的3次伤害，包括剧毒产生的普通毒。剧毒本体没有伤害，其产毒层数不受法术增伤放大，也不直接触发吸血或天怒转盾；详见[普通毒与剧毒](poison.md)。

中毒保留独立层与驱散标记，伤害归入魔法类型的法术伤害。法术增伤与只对中毒有效的普通增伤，在本次毒伤上作为同类输出增伤相加，不额外创建“中毒专属独立乘区”。例如100基础毒伤、20%普通法术增伤、30%中毒增伤，输出为150，再计算敌方易伤/减伤、魔抗、护盾及生命损失。

同一效果不会因同时命中“法术”和“中毒”标签重复应用。唯一装备增伤先择强；明确标为独立乘区的特殊效果另列，不能把所有增伤无条件合为一项。法术伤害不等于魔法类型：物理法术仍走护甲，魔法普攻也不自动享受法术增伤。竭心的生命移除标记继续排除法术增伤。

其中“毒限定增伤与普通法术增伤同类相加”是对用户本次要求的本游戏映射；不是声称 Dota 2 存在完全相同的卡牌增伤池。

依据：[Damage Manipulation](https://liquipedia.net/dota2/Damage_Manipulation)。

## 4. 状态抗性

- 不采用此前建议的50%人为上限。不同合格来源乘算剩余时长：`最终时长=原始时长×Π(1-有效状态抗性)`；例如两个20%来源得到36%抗性，5秒变3.2秒。散华家族相关抗性先择高，不能靠多把同家族重复计算。
- 状态施加时取抗性快照；后续抗性变化不追改已存在状态。缩短时长不等于降低控制强度，也不改变是否可驱散、是否穿透减益免疫。
- 作用范围按效果标记，不能只覆盖眩晕/沉默，也不能把所有负面状态一刀切缩短。光环、永久状态、延迟结算以及原作例外按来源排除；自身疯狂面具的沉默不当敌方减益缩短。
- 持续伤害不能因为缩短时长就默认少结算几跳。纯伤害毒层保持其伤害进度；对标记为会受抗性影响的“控制+持续伤害”，按原作机制同步压缩伤害间隔，保留未被驱散/免疫等外因中断时的总伤害。实际被提前驱散仍会失去后续伤害。
- 实现时将毒伤、减攻速、破坏等组件分开标记，逐来源落实原作例外；状态抗性与移动减速抗性区分。当前没有移动玩法，不引入移动减速抗性的新收益。

依据：[Status Resistance](https://liquipedia.net/dota2/Status_Resistance)。
