# 驱散规则与状态清除

更新日期：2026-10-16。规则设计记录，尚未实现到业务代码。

## 原作参考

驱散是一次清除已有状态的操作，不自动提供后续状态免疫。

| 类型 | 能力边界 |
| --- | --- |
| 弱驱散（Basic Dispel） | 清除标记为弱驱散可移除的状态。常见例子是部分沉默、缴械、减速和持续伤害；通常不能解除眩晕等硬控制。 |
| 强驱散（Strong Dispel） | 清除弱驱散可移除的负面状态，并能解除标记为仅强驱散可移除的状态，包括通常的眩晕。不能解除不可驱散状态。 |
| 死亡清除 | 原作中死亡通常移除大多数临时状态，但存在来源例外；本游戏死亡结束本局、护盾跨战重置单独处理。 |
| 不可驱散 | 弱驱散、强驱散均不能主动清除。是否随死亡结束需要另行定义。 |

对自身/友方驱散通常只移除负面状态，保留增益；对敌方驱散通常移除可驱散增益，保留其负面状态。特殊技能可明确覆盖这一默认规则。

原作光环效果通常不能靠一次驱散永久移除；光环或持续施加源仍存在时，状态可能持续存在或立即重新施加。

“能否驱散”“能否穿透减益免疫”“受控时能否施放”是三个不同问题，必须分别定义。

## 本游戏已确认规则

### 中毒

- 2026-10-17用户重做后统一分普通毒与剧毒，见[毒系规则](poison.md)，不再保留旧不可驱散伤害毒方案。
- 普通毒结算3次伤害后结束，可弱/强驱散；剧毒本身不造成伤害，每秒按层数生成普通毒，持续本场且仅强驱散。
- 一次弱驱散清除当前全部普通毒，剧毒保留并继续产毒；强驱散清除两类。剧毒产生的普通毒仍可弱驱散，不继承剧毒的强驱散要求。
- 驱散后仍可再次中毒，不附带免疫窗口。
- 中毒为魔法持续伤害，受魔抗减免，先扣魔法盾，再扣通用盾和生命。

### 撒旦之邪力

- 生命低于阈值时自动尝试开启。
- 成功开启时先对自身施加弱驱散，再获得限时高攻击吸血。
- 可移除普通可驱散缴械，不保证清除所有来源的缴械；不可驱散/仅强驱散来源按标记处理。
- 弱驱散不是强驱散，不据此获得解除眩晕的能力。
- 原作通常不能在眩晕时使用物品。本游戏是否为撒旦提供受控施放例外尚未确认；不能从低血触发推导出眩晕期间也必定成功开启。

### 黑皇杖（BKB）

- 提供手动/自动释放选择；自动模式受到控制后立即检查开启条件，但必须先满足物品使用权限。
- 开启时施加弱驱散，之后提供限时减益免疫和额外魔抗。
- 用户最新修正：BKB也不能在眩晕、妖术、禁用物品期间使用，撤销之前受控无条件施放的例外。沉默/缴械本身不禁止物品使用。多个状态并存时，只要有禁止物品使用的状态，就不能开启；自动模式不得绕过此限制。
- 弱驱散不会删除只能强驱散移除的眩晕。现存状态能否被减益免疫抑制，取决于状态的穿透标记；不能把“抑制生效”记录为“已驱散”。
- 不可驱散不等于穿透减益免疫。免疫期间状态的计时与恢复方式需要在后续状态系统设计中明确。

### 原力法杖 / 飓风长戟

- 受到指定控制后触发固定时长普攻保护，远程英雄触发冷却较短。
- 不解除控制，不提供强驱散，也不提供普遍的减益免疫。
- 普攻保护使整次普攻及其附带命中效果无效，必中不能穿透；技能和已有持续伤害仍正常结算。
- 飓风长戟额外给予短时攻速；与原力法杖共享同组唯一效果。

### 亚巴顿：无光之盾

- 用户已确认：护盾附带强驱散。
- 本游戏为自身施盾：成功施放时，先强驱散自身，再获得护盾。
- 清除弱驱散可移除及仅强驱散可移除的负面状态；不可驱散状态保留，不额外给予持续控制免疫。
- 用户已选择眩晕施放例外：魔法充足且冷却就绪时，允许在眩晕中自动施放护盾，先强驱散自身再获得护盾。不推广为所有强驱散技能的通用能力。
- 用户已明确沉默与妖术限制：被沉默或妖术时不能触发/施放无光之盾，即使同时眩晕也不能施放；不能先用该技能的强驱散清掉沉默/妖术，再声称本次施放合法。先检查施法资格，成功施放后才应用强驱散。

### 后续英雄：军团指挥官、潮汐猎人

- 用户已确认：两名英雄对应的解控效果均为强驱散。
- 军团的具体技能配置、潮汐的被动触发条件仍待确定；不能视为永久控制免疫。
- 潮汐是否按累计承伤触发、以及能否在眩晕期间触发，尚未确认。

## 后续配置要求（设计建议）

每个状态来源至少明确：

- 来源 ID、状态类型、正面或负面。
- 驱散等级：弱驱散可移除 / 仅强驱散可移除 / 不可驱散。
- 是否穿透减益免疫。
- 持续时间、刷新及叠层方式。
- 是否由光环或持续源重新施加。

每个驱散效果至少明确：驱散强度、目标范围（自身/友方/敌方）、清除增益或减益、触发时机，以及受控期间能否发动。

不能把所有控制压成单一“受控”标志：沉默限制英雄施法、禁用物品限制装备主动、缴械限制普攻、眩晕通常同时限制这些动作；本游戏的特殊自动触发效果要单独说明。
