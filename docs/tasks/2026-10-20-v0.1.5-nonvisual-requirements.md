# 0.1.5 非视觉代码需求

## 范围

本需求只覆盖可运行内容、规则、存档、信息展示和测试。**不包含**角色立绘、动画图集、卡牌图、特效、事件结局配图、页面视觉重绘或音频。

前置版本为 `0.1.4-D63A-8FD4-53E8`。0.1.5 不删除旧卡、旧英雄或旧事件；新内容只能追加，并保持旧存档可读。

## 一、四名英雄

新增英雄：女性敌法师、斧王、虚空假面、军团指挥官。所有技能触发、实际数值、状态生效／结束、伤害和治疗必须进入战斗日志，并随战斗快照保存。

### 1. 敌法师

- 成功普攻命中时，最多每 1 秒触发一次削蓝。
- 扣除目标**当前魔法的 2%**；记录真实扣除量，目标无蓝、未命中、无敌或伤害事件被完全阻断时不累计。
- 累计字段为“本场该敌法师对当前目标的实际削蓝总量”。
- 大招法力虚空：魔法伤害 `100 + 累计实际削蓝 × 0.6`；施加 0.2 秒眩晕，眩晕受状态抗性与驱散规则影响。

### 2. 斧王

- 每承受 4 次“成功命中且实际进入伤害结算”的普攻，触发一次反击螺旋。
- 反击螺旋为真实伤害，伤害公式为 `基础伤害 + 当前护甲 × 系数`；基础与系数进入平衡表，不硬编码 UI。
- 反击螺旋不可暴击、吸血、触发普攻命中效果、反射或再次累计“承受攻击次数”。
- 大招狂战士之吼：向目标施加 TAUNT；自身获得护甲。护甲持续时间等于经状态抗性处理后的实际嘲讽时长。

### 3. 虚空假面

- 时间锁定：成功普攻后按可配置概率尝试眩晕。成功后，目标**已经在冷却中的英雄技能**各增加 1 秒；已就绪技能不进入冷却，装备主动道具不受影响。
- 时间结界：对目标施加 `TIME_STOP` 3 秒。首版语义：暂停目标的普攻、技能施放、技能 CD 倒计时、装备 CD 倒计时、DOT 跳数与可驱散状态倒计时；目标不可使用物品。结界本身仍受状态抗性，但不可被普通／强驱散清除。
- `TIME_STOP` 不等同普通眩晕，必须单独建模、显示、保存与日志化。

### 4. 军团指挥官

- 成功普攻后按可配置概率追加一次攻击，并按可配置值治疗自身。
- 追加攻击不得再次触发军团自身追加攻击；其余暴击、吸血与命中效果沿用现有“追加攻击”资格规则。
- 大招决斗：向敌方施加 TAUNT，自身获得攻速；两者使用同一个经状态抗性处理后的实际持续时间。
- 首版没有击杀永久成长或额外胜负奖励。

### 5. 英雄共通要求

- 英雄技能耗蓝、CD、基础属性、斧王伤害常数、虚空时间锁定概率／眩晕时间、军团追加攻击概率／治疗量／决斗攻速等未定常数统一放在内容配置，不能散落在引擎分支。
- 所有新增状态在中途退出、重进、存档往返后数值与到期时刻一致。
- 单挑中 TAUNT 仍应保留为状态；不改变目标，但为未来召唤物／多目标预留正确语义。

## 二、两条新增正式流派

新增 `RAGE`（怒火）与 `FROST`（寒霜），并使正式流派总数变为 8：普攻、大招、暴击、护盾、恢复、中毒、怒火、寒霜。

### 怒火

- 主题：受伤后获得临时进攻收益、低生命作战、战吼。
- 首批单流派卡：怒意沸腾、受创激怒、狂战回响、不屈战魂。
- 羁绊按 2／3／4 卡种计数；档位效果写配置，首版建议分别偏向受伤攻速、低血攻击、战吼强化。

### 寒霜

- 主题：减速、冻结门槛、冰甲、持续法术伤害。
- 首批单流派卡：霜痕、凛冬甲壳、冰封脉冲、绝对零度。
- 羁绊按 2／3／4 卡种计数；档位效果写配置，首版建议分别偏向减速、冰霜易伤／护盾、短冻结或冰爆。

### 双流派卡池

旧 D1～D6 保持投放。新增以下 7 张，双流派池扩至 13 张：

| 卡牌 | 标签 |
|---|---|
| 沸血连斩 | 普攻＋怒火 |
| 霜影咏唱 | 大招＋寒霜 |
| 致命沸点 | 暴击＋怒火 |
| 冰甲反噬 | 护盾＋寒霜 |
| 逆境热血 | 恢复＋怒火 |
| 冻毒蔓延 | 中毒＋寒霜 |
| 极温崩解 | 怒火＋寒霜 |

要求：双流派卡在羁绊中各贡献一个卡种；同 ID 不得重复计数；旧 D1～D6 不因新增而下架。

## 三、卡牌与羁绊运行时

- 为怒火、寒霜补齐类型化 `EffectDefinition`，不能通过中文描述字符串驱动结算。
- 实现受伤、低生命阈值、减速、冻结、冰霜 DOT、冰霜易伤等效果时，明确 `DamageType`、攻击资格、驱散等级、免疫交互与叠加上限。
- 星级沿用现有 1／2／4 或显式逐星参数；CD、持续时间、次数、触发门槛不得被错误倍率放大。
- 30 张旧卡（已包含旧 D1～D6）与当前 6 羁绊不得回归；新增15张后合计45张。

## 四、事件扩充（8 → 16）

新增冰封祭坛、战旗遗址、流动商队、断桥索道、秘契祭坛、失控炼金室、猎人营火、月井回响。详细 optionId、结算语义、结果 ID 见：

[`2026-10-20-event-expansion-content.md`](../design/2026-10-20-event-expansion-content.md)

实现要求：

- 新事件及随机结果在进入节点时冻结；退出、重进、横竖屏、存档恢复不能重抽。
- 每个新增事件 3 个稳定 `outcomeId` 与 `artKey`；视觉层只读取 key，本需求不负责图片接入。
- 事件选择按 seed/nodeId 确定性加权；最近两次不重复同类，候选不足时只放宽为排除最近一次。
- 物品交付必须由玩家明确选定实例；安全箱物品默认不可交；奖励容量不足时零改动并进入整理。
- 新事件的金币、生命代价、掉落池、条件门槛全部配置化，并纳入经济采样器。

## 五、装备、信息与经济

### 装备与流派适配

- 为怒火与寒霜至少各增加 2 件可投放装备或组件；物品必须具备独立 ID、属性、效果、配方、尺寸、价格、掉落／商店门槛和图鉴信息。
- 配方图无环、产物唯一、材料消耗原子；装备不能使用卡牌升星逻辑。
- 新效果遵守已有唯一组、主动装备 CD、BKB、状态抗性、驱散和护盾规则。

### 技能与装备信息

- 英雄页与装备详情显示：基础数值、当前值、耗蓝、CD、实际状态／触发条件、主要数值与来源。
- 战斗 HUD 显示技能 CD 倒计时、当前／最大魔法、无法施法原因（魔法不足、眩晕、沉默、时停等）。
- 数值页必须读取共享计算结果，不在 UI 中复制公式；来源无法可靠拆分时只显示“总值”。

### 平衡

- 固定种子采样覆盖十英雄、八流派、难度与主要事件；输出胜率、平均战斗时长、死亡原因、金币净变化、掉落价值与事件选项使用率。
- 同时检查控制链：眩晕、沉默、缴械、TAUNT、TIME_STOP、BKB／强驱散的相互作用。
- 任何平衡调整改配置和采样阈值，不以删除失败样本达成通过。

## 六、存档与迁移

- 新增英雄、卡、装备、状态、冻结事件结果和事件 artKey 必须保存。
- 旧档读取后维持原英雄、旧六流派、旧事件内容，不因默认值替换已冻结内容。
- 新版读取旧档、旧版拒绝新版、战斗中存档往返、事件中存档往返都必须有测试。

## 七、验收最低线

1. 十英雄互相对战：每个新增固有技能至少各有一次成功、失败／免疫、存档恢复案例。
2. 怒火／寒霜 2／3／4 档与七张新增双流派卡均有运行时测试；旧卡池回归通过。
3. 16 类事件均可生成；新增 24 结局的 `outcomeId/artKey` 稳定、读档不变、失败事务零改动。
4. 新装备的配方图、唯一组、主动 CD 与投放门槛通过自动化验证。
5. 固定种子平衡采样完成；异常必须留下失败样本与战斗日志。
6. 全量单测、Android 构建、shared JVM／JS 编译通过；新增功能不得依赖 Android／`java.*` 写入 commonMain。

## 明确不在此需求内

- 角色立绘、攻击／施法动画、特效、卡图、装备图标、事件结局配图、UI 美术改版、音频。
- GitHub／Gitee 建库、推送与发布。
