# 装备、组件与合成提案

本文内容范围已纳入v1首版。2026-10-17已将24主要装备、5中间装备、组件和卷轴加入真实目录与战斗，29个配方按Valve物品数据核验，见[逐项证据与兼容别名](equipment-recipes-verified.md)。原作命名有“行家阵列”“赛莉蒙妮之冠”，本游戏保留专家阵列和历史内部ID兼容；先锋盾现正确消耗治疗指环。以下历史表描述范围，精确配方以核验表/EquipmentCatalog为准。物价、属性、CD仍为本游戏首轮参数，未完成平衡验收。

2026-10-17附毒规则重做已获用户采用：巫师每4秒附1层每跳6的普通毒；圣斧每4秒附1层产毒每跳8的剧毒并降低目标魔抗15个百分点；怪蛇攻击附1层每跳8的普通毒。巫师/圣斧同组唯一且共享CD，详见[毒规则](../rules/poison.md)。主动装备可战中手动/自动切换；BKB不追溯结束的控制，仅当前仍有可处理负面且权限允许时自动开启。

## 已确认原则

6个生效栏+3个备用栏；仅生效栏提供属性和操作。合成仅局外，组件/卷轴消耗且不可拆。种类品质固定。装备本身不贡献技能卡羁绊计数；后一句为设计提案，需要审阅。

## 尺寸与品质草案

- 装备栏按件数，物品尺寸只影响转入普通背包、安全箱和宝箱预览。
- 小属性组件/卷轴/大多数卡1×1；中阶组件1×2；主要成装2×2或1×3；少量金装2×3。尺寸按种类固定，不因卡牌升星而增大。
- 双流派卡部分1×2；在技能栏仍占一栏。三星卡保持种类尺寸，强化升星的空间收益。
- 所有物品建议上限不超过6×4、且第一阶段可能给出的必要物品不超过初始背包可容纳形状。
- 卷轴品质跟随其成品档次；组件白/蓝，成装蓝/紫/金按强度分档。不以“所有大件必金”自动推导。
- 单件具体尺寸和品级在数值表审阅时给出；本文件的范围不是可直接生成游戏资产的完整数据表。

## 表现与操作

### 多单位效果预留（用户要求，尚未制作召唤/幻象英雄）

已确认首版单挑改造，同时必须考虑后续召唤物、幻象。以下是具体结构提案，不自动定下多单位版本的全部平衡规则。

- 战场按单位ID维护目标集合，单位至少区分英雄本体/召唤物/幻象、所属阵营、所有者、存活及是否可选。当前仅两单位仍使用同一选择入口，不以固定enemy变量写死全部装备效果。
- 主目标与次要目标分开，目标筛选和效果应用分开。配置包含最大目标数、弹跳上限、是否重复命中、次要目标伤害倍率以及目标类型修正。
- 漩涡/电锤：单次闪电首先伤害当前目标；有其他合法敌人时才弹跳，建议同一条闪电不重复命中同一单位；无其他目标则结束，不能将未用弹跳次数折算为本体额外伤害。
- 电锤静电反击：每次触发只命中有限目标，并设置内部CD；多召唤物攻击不允许同一tick无限反击。具体数量/CD后续多单位平衡时确认。
- 专家阵列/怪蛇：首版已确认的单体追加伤害与未来次要目标段分别配置，不把“没有次要目标”解释为自动对本体重复发所有弹道。未来有召唤物时，单体追加段保留还是替换为多目标段属于后续设计决定，不双算。
- 怪蛇主目标中毒保留；未来次要目标是否附带自带中毒，要单独标记。不得因复用一次普攻事件就把所有装备、卡牌和羁绊效果复制到每个次目标。
- 追加段/闪电标记来源、是否可暴击、可吸血、可触发命中以及是否为反射伤害，防止闪电触发闪电/毒反击递归。
- 首版不实现幻象继承装备、分身伤害倍率、召唤上限、站位移动等完整系统；这些在对应英雄加入时设计。预留配置不代表这些玩法已完成。

推推棒触发时角色向后滑移、对方略被推离，出现风轨及保护时间条。该位移只影响表现，不修改攻击距离判定；普攻保护为真实逻辑效果，且必中不穿透。

三类盾条分别标识，受击显示先消耗何种盾。卡牌和装备提示明确写“唯一：效果组名”“可弱驱散/仅强驱散/不可驱散”“能否在受控时发动”。
