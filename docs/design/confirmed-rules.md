# 已确认的首版规则

以下为用户已明确确定的规则；具体数值若未确认，不在本文件自行补定。

2026-10-16补充：用户要求将剩余内容集中确定，授权下的默认决策与首轮数值见[v1定稿](v1-decisions.md)，与逐条确认的历史记录分开。

## 挑战与风险

- 单机游戏。首版固定 5 场 AI 英雄对决，后续目标是英雄、怪物与首领混合挑战。
- 路线：第1战 → 事件 → 第2战 → 事件 → 第3战 → 撤离/休息 → 第4战 → 事件 → 第5战 → 通关。
- 入场前只知整体难度；每场开战前揭示敌方英雄和主要流派，允许整备。
- 每战胜利固定三选一：回血、金币、随机物品。强度随关卡提升；物品领取前只显示类别与品质，领取后揭晓具体内容。
- 第3战后可携带途中所得撤离；继续则免费回复一定比例生命。
- 所有来源造成生命归零均结束本局。带入物、途中物和本局金币全部失去，仅安全箱内内容保留。
- 目标宝箱必须全通关才能领取，整箱自动入局外仓库，不受局内背包容量限制。
- 随机事件提供情境选项：可能无损离开、必须付代价，或满足装备/技能/资源条件才解锁特殊选择。显示风险收益类型，隐藏具体概率和数值。
- 战斗退出后恢复同一场配置与既定结果，不允许退出重抽。
- 战斗达到60秒按双方剩余生命百分比判胜负；比例相同或同归于尽算挑战失败，按死亡规则结算。只比较生命比例，不计护盾。

## 容器和物品

- 装备 9 栏：6 生效、3 备用。技能卡独立栏位，初始4、永久扩至8。
- 普通背包初始4×2，最大6×4；安全箱初始2×2，最大3×3。首版均开放完整成长上限。
- 普通背包与安全箱允许90度旋转。每种物品固定尺寸；高品质总体倾向更大，但允许例外。
- 安全箱可放任意物品类型，不可放金币。物品在安全箱内不提供战斗效果。
- 高难度关键材料可设计为旋转后仍放不进当前安全箱、但普通背包装得下。
- 仅准备阶段和战斗间隙允许移动、装备、替换和丢弃；战斗中全部锁定。
- 换装导致最大生命变化时，当前生命保持原百分比：新生命=原生命/原上限×新上限。该变化不视为治疗，不触发治疗类效果；内部保留小数精度，避免反复换装因取整刷血。
- 领取时空间不足可现场整理，也可放弃新物品。途中新物品可立即装备使用。
- 装备、技能卡、材料、卷轴不堆叠。部分恢复品允许限量堆叠。
- 仙灵之火、奶酪不堆叠；生效装备栏每栏单份，战斗使用后不从背包补充。
- 所有战斗间整备阶段可用恢复道具。仙灵之火、奶酪支持战斗中手动/自动使用。
- 局外仓库首版不限容量。局外资产与本局风险资产隔离，剩余局外金币不会因死亡损失。

## 宝箱、鉴定与刷新

- 内容在首次预览前固定。占格可见，部分品质或具体物品揭示；鉴定不会改变内容。
- 随机鉴定揭示若干未完全公开物品，可能揭示品质，也可能完整信息，不能指定目标。
- 鉴定立即扣局外金币，并提高该箱入场价；放弃不退鉴定费。揭示数量、品质越多越高，充分鉴定时票价可超过箱子价值。
- 宝箱首次生成时锁定计价基准，后续不随阶段调价重估；已生成内容不变。
- 初始每批4箱，不同品质随进度生成，允许重复品质；后期增加数量、维度。
- 统一列表，可按票价、品质、主题、难度筛选排序。主题给出产出倾向，不保证目标材料。
- 新一批生成时保证低票价入口，但不保证玩家付得起。
- 主动刷新单箱，保留主题与难度，重抽品质、内容、票价，清除该箱鉴定进度；不保护最后一个低票价箱。
- 免费单箱刷新次数随时间逐次恢复、有储存上限，用完可付费。
- 选择一箱入场后其他箱子不保留；挑战结束整批换新，原鉴定费不返还。
- 材料来源按类型分工，关键材料有隐藏保底；保底箱生成即消耗保底资格，刷新/放弃/撤离/死亡不返还。

## 英雄、卡牌、属性

- 英雄免费选择已解锁者。初始开放部分，其余用金币/材料永久解锁；死亡不失去英雄。
- 首批：主宰、天怒法师、幻影刺客、亚巴顿、瘟疫法师、冥界亚龙。技能细节除明确确认项外仍是提案。
- 英雄自带大招与被动，不占技能卡栏。首版无英雄局内等级与天赋。
- 六英雄机制更新：主宰被动为暴击，大招1秒无敌、强驱散且斩击次数随攻速变化；天怒法术伤害转魔法盾且下场清空；PA沿用当前技能草案；亚巴顿被动魔霭诅咒；NEC被动竭心光环、大招幽魂护罩且要求避免过短CD；Viper被动毒性皮肤，大招蝮蛇突袭施加破坏。具体新数值及交互见combat-content.md提案，不自动照搬原作。
- 大招同时要求魔法足够、冷却就绪；默认随时间回蓝，攻击/受击回蓝由卡牌赋予。
- 生命跨战保留；魔法回到英雄初始值、技能冷却就绪；剩余护盾清空，下场重新计算开场护盾。
- 属性换算采用 Dota 2 公式；英雄基础数值及技能强度自行平衡。
- 六流派：普攻、大招、暴击、护盾、恢复、中毒。
- 卡牌直接提供效果，按生效栏内不同卡计2/3/4张羁绊，三档效果累加，多个流派可同时生效。
- 同名重复卡单卡效果可叠加、羁绊仅计一种。每卡最多2标签，双标签多为高级卡。无英雄/主属性/近远程装备门槛。
- 2026-10-17明确例外：奥术回响开场免费施放与首次CD+50%均为同名唯一；余波固定减大招CD可升星与多卡相加，沿用一/二/三星0.5/1/2秒。战意激昂最多3层、每层独立4秒；弱点洞察最多3层减甲、持续本场可驱散。
- 卡牌品质按种类固定。3张同名同星合下一星，最高三星；仅局外合成，不额外收金币/材料，不可逆。
- 升星只强化数值，不增机制；有损压缩，二星约2倍、三星约4倍作为初始试算，概率/CD单独平衡。
- 暴击试用 Dota 2 高倍率优先判定、成功停止、不连乘及伪随机；闪避乘算、伪随机，必中绕过闪避。
- 攻击吸血：生命伤害全额计入，护盾吸收伤害按50%计入。未命中/普攻保护挡掉的攻击不吸血。

## 护盾、状态和指定装备

- 2026-10-16补充：普通攻击吸血、恢复作用范围及叠加、状态抗性按Dota 2机制处理；中毒为法术伤害，按法术伤害增幅策略结算。公式、版本参考与本游戏特例见[恢复与状态规则](../rules/restoration-and-status.md)，替代此前相关待审选项。

- 通用/物理/魔法盾分开，先扣专用盾再通用盾；纯粹伤害直接扣生命、无视所有盾。
- 同来源护盾重复施加取新盾量与当前剩余量较高者，刷新时限；不同来源可叠加。
- 护盾转伤害以三类当前剩余总量计算；按具体技能决定是否消耗、伤害类型。
- 2026-10-17重做：普通毒每层结算3次魔法法术伤害后消失，正常3秒，可弱/强驱散；剧毒本体不伤害，每秒按自身层数添加等量普通毒，持续本场且仅强驱散。旧不可驱散伤害毒方案由本次规则覆盖，详见[毒系重做](../rules/poison.md)。
- 天怒法伤转魔法盾允许同来源持续累计，是一般同来源覆盖规则的明确例外；转化率30%，本被动盾量上限为最大生命100%，下场清空。只计实际法术生命伤害，敌方护盾吸收部分不计入。
- NEC竭心光环沿用原作生命移除标记的魔法伤害结算，受魔抗和魔法/通用盾影响，不按穿盾纯粹伤害处理。
- 破坏仅禁用英雄被动，不禁用装备被动、技能卡或羁绊。
- 亚巴顿无光之盾有强驱散，魔法足够且冷却就绪时允许眩晕中自动施放，但沉默或妖术时禁止触发/施放；叠加眩晕也不能绕过这些限制。施法资格先检查，通过后才执行强驱散。
- 巫师之刃/圣斧共享唯一中毒被动，同时装备取圣斧版本；基础属性各自生效。
- 原力法杖受控触发固定时长普攻保护，不解控；远程CD更短。整次普攻及附带效果无效，必中无效；原有持续伤害与技能照常。
- 飓风长戟继承保护并给短时攻速，与原力法杖同组唯一。附推开视觉，不建立站位玩法。
- 撒旦低血触发、开启弱驱散及短时高攻击吸血。
- BKB及部分消耗品可手动；BKB自动模式受控时立即检查，但眩晕、妖术、禁用物品期间不能开启，撤销此前受控施放例外。沉默/缴械本身不禁止使用物品；详见驱散文档。
- 手动物品实时释放，战斗不暂停；保存指令与战斗状态，退出不能撤销已发生的操作或重抽结果。
- 玲珑心减CD影响英雄技能、技能卡和装备；同组唯一效果不叠加。
- 疯狂面具自动开启提高攻速，期间沉默自身、不能放大招。
- 装备CD按本游戏时长重设，不照搬 Dota 长CD。
- 装备冷却跨战继承，进入下一场前将上场结束时剩余冷却一次性扣减30秒，最低0；不直接清零。消耗品数量不恢复。英雄技能仍按既定规则每场冷却就绪。
- 单挑装备改造方向已确认：魔龙枪射程转普攻伤害收益，夜叉/双刀移速转额外攻速，专家阵列/怪蛇采用不触发暴击、吸血和命中效果的单体追加物理伤害；具体数值未定。
- 电锤与怪蛇必须预留召唤物/幻象等多单位目标能力；首版仍以单挑为主，不因此增加召唤/幻象英雄实施范围。

## 商店、合成与成长

- 装备/卡牌可通过带出、局外商店与合成获取；局内无购买、制作与合成。
- 装备配方无需永久解锁，每次消耗组件及配方要求的卷轴；无卷轴配方只消耗组件。
- 成品种类品质固定，不做组件随机词条；首版装备不可拆解，后续再考虑部分可拆。
- 基础卷轴固定供应，高阶卷轴轮换或挑战获取；商店偶尔售高价值物品。
- 技能卡明牌购买。轮换/珍品按时间更新，也可付费换货且不重置自动刷新时刻。
- 轮换商品限量库存，珍品通常一份；挑战结束不刷新商店。
- 物价按玩家阶段与需求模拟调整，不做真实供需市场。
- 普通物品可卖；关键成长材料与救济物资绑定、不可卖。
- 破产救济有次数，逐次按时间恢复、设储存上限；用尽需等待，不提供无限免费挑战。
- 领取救济时若没有适用低价箱，补充/替换出一只低成本箱供入场补助使用；仍消耗救济次数，不发可自由使用的补助金币。
- 首版局外成长为英雄解锁、技能栏和容器扩展，不永久加战斗属性；有限属性成长仅后续可选。
- 成长用金币、通用材料和专用材料。门槛结合首次撤离/通关成就及累计通关。
- 专用材料与通用材料可放安全箱，只受实际尺寸限制；每份独立占格。
