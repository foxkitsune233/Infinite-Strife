# Android整备交互与H02首批接入

用户要求继续实现并改善“全是点击按钮”的原型体验。本批沿用原生View，不增加Compose/Material依赖，不修改已定玩法。

视觉采用深墨绿色背景、暖金行动色、青绿安全色，品质色只用于物品。主菜单变为有实际存档状态的远征入口；挑战页用候选箱卡片、五战进度、双方生命/魔法条；整备页用真实物品网格与仓库物品卡。

交互：点物品选中，再点空格放置；长按物品拖至装备/技能/背包/安全箱，合法落点明确高亮；底部工具条提供旋转摆放方向、详情与更多操作。旋转仅改变待放方向，成功放置且存档后才改变物品。无效落点/取消拖拽不改库存。战斗中锁定物品移动。所有操作复用InventoryRules与原事务存档，不用视觉交换绕过类型和容量检查。

可访问性：至少48dp操作区；拖拽有点选替代；图形状态提供文本说明，容器提供无障碍操作入口；文字支持系统字号。系统栏/手势区域使用WindowInsets。动效仅作为选中/按压反馈，不控制规则状态。

H02首批：新增纯Kotlin DamageEvent/防御快照/结算结果，使用H01的DamageType、AttackClass和EffectFlags。物理/魔法/纯粹与生命移除分清；保留实际生命伤害、盾伤及吸血资格，不把盾伤当生命伤害。DuelEngine现有伤害调用经新管线，暴击用18工具，保持原存档字段与可恢复RNG行为。10/17/19和完整卡装备触发后续继续，不用空调用伪称接入。

不接入H01全部物品投放；未执行效果不能进入真实掉落。restore作为新内容恢复流派ID，旧life/evade只留旧原型兼容，新挑战不使用；现有旧原型映射restoration在迁移时明确转换，不改旧资源语义。

验证按用户要求只静态检查和编译，新增业务测试先交外部执行；不启动模拟器。手动验证表覆盖拖放、选中、旋转、生命周期、不同宽度/字号、存档失败、战斗实时按钮。暂不能声称视觉已在真机验收。
