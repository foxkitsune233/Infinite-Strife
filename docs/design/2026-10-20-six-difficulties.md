# 六档难度与战前侦察（规则 v4）

用户最新要求覆盖上一轮“仅加强困难”：简单维持原样，普通也加强，正式扩成六档。应用发布版本不在本次调整；v4 是局内规则版本。

倍率乘在敌方自身构筑的基础属性上；额外攻速、护甲、卡种数量、二星和金卡上限同步递进。卡种最多8、装备最多6。装备预算是上限，不是自动补足的额外属性。不根据玩家当前战力动态调敌人。

选装先为主动装备预留预算，按实际 EquipmentCombat.activeItems 筛选；共享唯一组覆盖后的无效主动不重复计算。紫怨/天堂之戟/BKB/疯狂面具/防护及恢复主动沿用真实运行时、正常冷却与使用条件。原力法杖等纯受控触发装备不冒充可手动开启的主动装备。普通前3战不追加控制装备，困难起可提前出现；简单不新增控制装备。

本表为首轮值，需固定种子实战采样判断胜率，不能以倍率单调或编译通过断言平衡已完成。

## 侦察信息

| 难度 | 战前展示 |

同一场预览和开战共用 EnemyBuilds.preview，隐藏选择固定按 ID 排序，不用 RNG、不扣钱、不支持反复刷新套情报。EnemyIntel 只把允许显示的 ID 交给界面；隐藏物品无详情入口、无隐含无障碍名称。敌人英雄和主流派仍显示，避免完全盲打。

## 宝箱、掉落与经济

新一批至少6箱，按0..5各出现一档，10次通关后8箱（额外两个低档）。难度与箱子品质分开；不拿箱子颜色代替难度。已经显示的箱子不重抽。

成装最低掉落难度按售价：<2500普通、2500..3499困难、3500..4499精英、4500..5499大师、>=5500噩梦；对应卷轴跟随成装。基础/中间组件与成长材料不受此价格分档限制，原有品质、通关次数和箱内尺寸条件继续生效。低档材料仍可合成，不新增强制禁止携带旧装备的规则。

同品质票价倍率：1/1.5/2/2.5/3/4，旧0..2档票价不改。金币逐战表新增高三档：精英60/90/125/170/220，大师80/120/165/220/285，噩梦105/155/215/285/365；原三档金币不变。
