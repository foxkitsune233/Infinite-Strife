# 《无尽纷争》Android 1.0 完整剧情文本 · 第一稿

日期：2026-11-04。状态：任务与英雄初见为审阅稿；十条个人结局已扩写并导入黑幕字幕预览，正式登顶触发待接。

同日修订：亚巴顿改为离乡征战数年的骑士，家乡毁于邪教；初见和主线不揭露教团崇拜的对象，其信仰来源仅在个人结局揭示。

核心采用用户最新修正：获取圣剑、返回过去，反而导致英雄再次失败。原先“成功弥补错误后归来”的收尾作废。

## 一、世界观与演出约定

### 世界的六条规则

1. 转生之塔立于诸界交汇处。失去故乡、重要之人或人生转机的英雄，循着圣剑的传说来到这里。营地是暂时停战、交易与签订远征契约的地方。
2. 玩家是领队，负责物资、配装、情报与出战安排。英雄接受的是一次次合作；可用英雄不等于永久盟友，远征中的其他英雄也是拥有自己目的的真实竞争者。
3. 技能卡保存可以学习、组合的战技，八流派是营地对战技的分类。宝箱、鉴定、合成、护芯与安全箱服务于远征，不另造八个国家或八个阵营。
4. 圣剑确实可以打开通向持有者过去的短暂归途。它将英雄此刻的力量一同带回，却不会替英雄判断该救谁、该相信谁、该在何时停手。一次登顶只回应当前挑战者；其他人仍必须争取自己的机会。
5. 英雄第一次持剑归返的结果均为失败：有的促成旧灾难，有的阻止了原先的损失，却造成更严重的后果。原因具体来自英雄带回的力量、掌握的信息和作出的选择；不以突然出现的诅咒统一解释。
6. 归途结束后，英雄被塔的回路送回营地，保留装备与记忆。诸界交汇处不随某个故乡的历史一同改写。圣剑作为登顶所得继续保留，英雄继续可用；剧情不扣除装备、清档、强制离队或撤回已得奖励。他们对失败作出不同解释，并再次准备出发，这便是“无尽纷争”。

这是本作独立改编设定，不作为任何角色原作背景的复述。称谓采用当前游戏：主宰、亚巴顿、敌法师、斧王、虚空假面、军团指挥官、天怒法师、冥界亚龙、幻影刺客、瘟疫法师。

### 文本使用方式

- `P00`：序章，一次播放。
- `H01`—`H06`：六位初始英雄的初见。分散在首次查看该英雄时阅读，不开局连续弹六段，也不增加解锁门槛。旧档缺少这些角色时，以实际可用状态为准。
- `J01`—`J24`：现有任务节点领奖后的文本。三选一节点共享一段，不假定玩家完成某条特定难度目标。
- `J07`、`J10`、`J13`、`J17`：四位获取英雄的重点对话，五至六句。玩家若已通过购买拥有角色，仍按“确立本轮合作”理解，不说“第一次见面”或重复解锁。
- `T00`—`T20`：塔入口与里程碑。台词不把当前楼层对手固定为某一名英雄；楼层实际敌人沿用游戏规则。
- `E01`—`E10`：当前登顶英雄对应的个人结局，一轮只播放一条。首次全稿揭示圣剑造成失败的真相。其他结局可在不同英雄完成挑战后分别阅读，不强制全收集。
- `R01`—`R04`：失败、撤离和重复登顶的短补充。
- 每行“角色：台词”为一页；同段最多两名立绘角色，左右位置固定，说话者高亮，另一人压暗。括号内是演出说明，不显示为对话正文。
- 个人结局使用独立的全黑字幕播放器，已在 Debug 测试模式提供预览；普通任务与初见仍沿用立绘对话设计，暂不导入未经确认的台词。
- 普通任务一至三句；初见四句左右；重点获取五至六句；个人结局扩写为 12 段叙述字幕，再接 3 段共通尾声。文案不新增实际物品、支线条件、阵营好感或额外奖励。
