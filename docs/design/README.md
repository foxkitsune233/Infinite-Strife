## 首版目标

完成一次可持续循环：查看宝箱线索 → 鉴定和估值 → 局外配装 → 付金币进入 → 自动对决与部分物品操作 → 战利品取舍 → 撤离/死亡/通关 → 仓库、交易、合成和成长。

首版使用固定五战路线、六英雄、六流派。军团与潮汐、混合怪物/Boss、永久属性成长留在后续范围。

## 三种设计侧重

- 推荐：先完成物资与挑战闭环，再丰富六流派。优点是能尽早验证死亡损失和宝箱投入；需要独立平衡经济与战斗。
- 战斗先行：先实现所有英雄与装备交互。优点是更早验证构筑；缺点是无法验证搜打撤的核心风险收益。
- 内容精简：先做少量英雄和装备完成闭环，再补齐已规划内容。验证更快，但完整首版仍需补齐六流派。

推荐第一种。具体实现步骤须在设计审阅通过后再制定。
