# 宝箱、经济、成长与事件提案

本文件为经济内容与首轮数值基线。用户明确规则见confirmed-rules.md，其余首版选择见v1-decisions.md；历史待审措辞不再要求用户重复回答。具体权重与未填参数仍需补表，不能视为已完成配置或已验证平衡。

## 新存档与第一轮

建议起始金币1200，主宰、亚巴顿免费开放；赠送一套基础组件和四张不同一星蓝卡（A1/A2/S1/R1）。赠送物不绑定以外的普通掉落继续正常交易；初始赠送物建议绑定避免重建式经济漏洞，此项需确认。初始4技能栏、4×2背包、2×2安全箱。

预览 → 可选鉴定 → 选英雄/从仓库装配 → 购买入场资格 → 物品从仓库转入本局 → 节点挑战 → 三种终局结算。

付款与转物为同一事务：失败不能出现扣票成功但物品仍在仓库等不一致。进入挑战后原宝箱批次失效，本局目标宝箱保存到挑战对象，不再受商店/价格刷新影响。

## 宝箱展示、主题与成长开放

主题建议：武备、秘术、综合补给、背包工程、技能传承、安全箱工程。前3类偏装备/卡/补给，后3类偏专用成长材料，所有主题仍可能含其他物资。

初始4箱，累计3次通关扩至6箱、10次扩至8箱；首版上限8箱（提案）。只增加选择，不增加同时进行的挑战数。

每箱固定字段：唯一ID、主题、品质、难度、固定物品列表及坐标、揭示状态、锁定价格快照、生成时保底来源、已付鉴定费、当前票价。物品必须先全部生成并摆放成功，再对玩家展示。

预览网格建议6×6，物品不重叠。全部可见占格轮廓；默认随机公开约1/3物品品质、至多一件完整物品，其他未知。原始内容留档，不因鉴定重抽。视觉颜色区分“箱子品质”和“某件物品品质”。

每批初始保证至少两种箱子品质，至少一只低票价箱；不保证付得起。单箱刷新保留主题、难度，但不再保护低票价条件。首版仍全为5战，难度仅调整敌方预算/奖励，后续才可配置路线长度。

## 鉴定与票价草案

每次鉴定随机挑1～3件未完全公开物品，不在同一次重复选同一件。未知物品70%只揭示品质、30%揭示全部；品质已知物品揭示全部。全部公开后停止鉴定。

价格快照锁定每件物品的参考价、可出售物品回收价。绑定材料可有参考价值但回收价为0，不能在UI混成“可卖出的金币”。

T0由挑战难度、箱子品质和初始公开信息决定；额外鉴定后：

`票价=T0+各新增品质揭示费+1.10×新增完整揭示物品的锁定回收价值+绑定材料揭示附加价`

品质揭示费按白/蓝/紫/金先取10/25/60/120；已展示品质后再揭示完整物品，不重复收该次品质揭示费，只加完整揭示项。绑定材料完整揭示按材料档次加固定价，不能按0价值免涨价。

这使信息越完整成本越高；全揭示后票价可超过全部可售内容的回收价值。是否把绑定材料的非货币价值纳入“实际价值”需在界面解释清楚。票价不随用户之后的阶段或仓库存量重估。

鉴定即时费用：首轮20金币，同箱每次+10，封顶60；每次完整展示“本次鉴定费”及“鉴定后票价会变化”，实际结果出现后显示涨价明细。已付费不返还。鉴定和票价扣款都只用局外金币。

单箱免费刷新上限3次、每30分钟恢复1次；付费30金币/箱（不递增，作为初稿）。离线恢复以时间差计算，上限封顶，不积累无限次数。刷新即生成新箱，可能消耗隐藏保底。新箱不是原箱免费再掷骰。

## 难度与首轮经济建议

| 挑战档 | 基础票价（未含品质/揭示） | 目标箱可售内容参考总值 | 战后金币选项 B1/B2/B3/B4/B5 |
| --- | --- | --- | --- |
| 低成本 | 60 | 180～350 | 20/30/40/55/70 |
| 常规 | 150 | 450～800 | 35/50/70/90/120 |
| 进阶 | 350 | 1000～1700 | 60/90/120/160/210 |

品质和难度相关但不强绑定；上表为生成预算区间，不能用单个箱子估值强制反推敌人强度。初版先开放低成本/常规，首次通关后开放进阶。

金币奖励三选一意味着不能同时假定每局收获整列金币、全程回血和物品；平衡验收必须按实际选择模拟。撤离不退票；通关不再额外凭空发“一箱入袋”字符串奖励。

战后回血建议最大生命15/17/20/22/25%，金币按表，随机物品按回合品质池；类别/品质在选择前可见，具体物品选择后揭晓。是否可抽材料：建议允许，种类明确显示为“材料”。普通事件药品只负责补给，不重复发固定胜场奖励。

第3战继续休息恢复最大生命35%，不额外发原型中的100金币。该回血替代还是叠加战后奖励？建议先选第3战奖励，再到休息/撤离，继续时额外恢复，需用户确认。

## 成长材料及隐藏保底

材料不堆叠。通用材料“残存精华”1×1；专用材料为背包织件1×2、技能刻片1×1、安全箱锁芯3×2、高级安全箱框架3×3。

安全箱2×2装不下3×2锁芯，但初始4×2背包可以旋转后装下；3×2安全箱装不下3×3框架，需要先把背包升至4×3，避免物品永远无法携带。

锁芯/框架主要在途中高风险事件有机会拿到，也可出现在目标箱。目标箱通关整箱入库是另一条获得路径，不要求现场背包容纳；若希望强迫背包升级，必须把对应升级门槛单独写明，不能依赖目标箱容量。

建议：通用材料常见于事件/物品奖励/目标箱；背包织件偏背包工程，技能刻片偏技能传承，安全箱材料偏安全箱工程；关键专用材料绑定不可卖。

隐藏保底提案：按材料类别分别计数，对应主题通关但本局未带出该类别材料时+1；成功带出重置。初始阈值背包/技能4次、安全箱6次。未解锁、当前不需要的材料不触发保底。

阈值达到时记录一次待生成资格；下次生成匹配主题且难度合格的箱子，强制一件对应材料并立即消耗资格/重置计数。批量生成逐箱结算，不能同一资格给多个箱子。保底不另赠一份物品，仍受箱子物品预算。生成后刷新/放弃/失败不返还（已确认）。

待确认边界：以“生成即消耗”为前提，是否计数从生成后开始、还是完成该箱才开始新轮计数。建议生成后立即开始下一轮；同次通关如成功带出对应材料，再重置。

## 商店与出售

建议常备：低价组件、药膏/吃树、基础卷轴；轮换6项，珍品1项。每2小时按固定时间格更新；付费80金币立即更新轮换/珍品，不改变下一次自动时刻；每次购买有确定库存，默认卡1～3张、装备/高阶卷轴1件。

珍品栏每轮30%概率有货，可能高阶成装/稀有双流派卡/高阶卷轴，需进度解锁。所有卡明确显示星级，首轮商店仅卖一星，二/三星主要通过合成（提案）。没有货时明确显示“本轮无珍品”，不伪装有奖。

物品买价用基准价×阶段系数×需求系数，建议阶段0.9～1.1、需求0.9～1.1，总波动限0.8～1.2。需求依据近期购买/缺失材料标签，不根据当前钱包压榨式涨价；每次商店刷新锁价，购买后不立刻抬价。

卖价建议同一快照买价的40%，并把跨阶段最大差限制在不会无风险买卖套利的范围。卡牌二/三星卖价按材料成本折损计算，不因为不收费升星而产生3张卖价低于1张的套利。

绑定物不可卖但可正常带入、放安全箱，安全箱外死亡仍掉落。绑定组件参与合成则成品继承绑定，防止救济物转成成装后出售；绑定与普通卡混合升星也继承绑定。绑定是否允许丢弃建议允许并二次确认。

## 破产救济草案

判定：局外金币低于本批最低票价，且可售资产回收总值低于120金币，且没有正在进行的挑战。绑定物按不可售处理；不得把存有大量可售金装的玩家判为破产。

次数上限2，每2小时恢复1次，离线可恢复。每次发绑定基础武器、绑定药膏和一张仅抵扣低成本箱入场费的补助凭证；不直接发可用于付费刷新的无限金币。补助覆盖当前票价上限100金币，超过需自己补足；凭证只在成功入场时消耗。

重要分支待审：若主动刷掉所有低价箱导致凭证无适用目标，建议救济同时提供一次“补充低成本箱”替换入口，保留常规单箱刷新不保护低价箱的既定规则。这是新增救济机制，需批准，不能隐含加入。

| 事件 | 选项与提示 | 隐藏结算提案 |
| --- | --- | --- |
| 废弃补给站 | 搜索：可能药品/受伤；离开：无收益无风险 | 搜索70%药品，30%掉最大生命10% |
| 锈蚀工坊 | 强拆：可能组件/受伤；交金币稳妥取件；离开 | 强拆60%组件/40%伤害；付费固定小组件 |
| 残破书库 | 深入：可能技能卡/中毒伤害；拥有大招羁绊可安全研读；离开 | 获取一星卡，受伤当场结算，不留下局外毒 |
| 坍塌仓室 | 左路：可能材料/受伤；右路：损失金币换安全通过 | 无无损选项，但明确显示风险类型 |
| 保险库残骸 | 搬走锁芯：占用大空间；拆解取通用材料；放弃 | 满足进度时生成锁芯，容量不足先现场整理 |
| 技术终端 | 消耗一份指定材料换技能刻片；冒险操作；离开 | 专用材料定向转换来源 |
| 临时医棚 | 交本局金币治疗；用一份药品强化治疗；离开 | 不算商店，不出售商品；若不接受局内付费治疗可删此事件 |
| 拦路者 | 交金币；交一件可交付物品；强闯可能受伤 | 允许安全箱是否被要求交物须明确，默认不强取安全箱 |

选项显示类别风险而非概率/伤害精确值。存在致死可能的选项显示“可能死亡”，不改变隐藏精确数值规则。

## 容量、结算与退出

战后随机物品先揭晓到领取界面，整理时暂存这一次奖励，未确认入袋前不算拥有。退出后仍是同一件，不可重抽。最终领取可放弃，不默认换成金币。

撤离把持有物和本局金币事务转入仓库/钱包，安全箱物也仅转存一次。死亡只转存安全箱内容，本局金币归零。通关先领取第5战三选一，再把所有持有物和目标箱一起入库（待审）。每个结算操作有唯一ID，防止重启重复发物。

整备、事件已选结果、鉴定结果、商店库存、补助次数、隐藏保底均持久化。时间恢复采用存档记录的最大已见时间防止倒拨倒扣；首版不做联网校时/反作弊，玩家修改系统时间不是安全保证。
