## 迁移顺序与统一验收

1. **远征闭环**：先补敌情预览、事件结果、战斗结算，再验证从出发到撤离或通关。新行为在普通远征和读档恢复两条入口各验证一次。
2. **整备与成长**：完成技能卡分类、资源图鉴、商店与合成反馈，并核对窄屏下的可点范围和文本截断。
3. **转生塔与剧情**：完成营地入口、楼层、三选一、授予和结局，再验证跨次存档与奖励唯一性。
4. **导出验收**：在 Windows 竖屏窗口和 Android 安装包检查字体、贴图、层级、滑动、点击、倒计时和恢复流程。截图和操作记录随对应功能验收留档。

美术优先复用 `assets/android/` 中的 Android 原图与动画。新增粒子、转场和反馈可由 Godot 实现，记录使用场景与触发条件。
