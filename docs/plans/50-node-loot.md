# 50 副本节点掉落与资金携入

用户确认：战后取消全部三选一；敌人物品与金币直接生成。事件可多物品、全种类品质。物品先放待拾取区，经不可跳过的鉴定后拖入合法容器才取得。当前节点可反复整理，离开确认丢弃剩余掉落。入场可从营地钱包携带金币；死亡损失本局全部金币；最终目标箱保持通关直接入库。

实现计划：
1. shared新增固定节点掉落、已拾取ID、鉴定时间与来源模型，拾取事务/节点继续/携入资金原子校验。
2. 战斗胜利冻结掉落并发金币；事件奖励转待拾取且不再受背包容量阻塞；事件结果仍固定不可重抽。
3. 存档v11追加节点掉落，兼容v1～v10；旧REWARD迁移/继续接口不提供新三选一UI。
4. 副本整备下方待拾取，上方容器；沿用拖放和二级预览。事件箱开启动画+顺序鉴定，时间保存且不能跳过。
5. 入场金额选择、节点离开确认、第五战拾取后通关；更新采样器与外部验收表。仅编译与静态审查，测试外部执行。

首轮掉落数沿用建议：普通战斗1～3、第五战3～5；物品收益事件2～6。数量和品质按固定随机/难度/进度与价值权重产生，后续平衡可调。金币自动进入runGold，不占格或安全箱。

版本：本轮尚不改0.1.3已发包的随机索引；完成后另登记新修改构建，禁止复用已发行索引。

收尾补充：已拾取/带入的物品也可拖回当前待拾取区，当前节点内可以再取回。放下期间不提供属性或安全箱保护，离开确认时一并丢弃。事件物品收获附带当前同战次金币奖励的一半，直接进入本局资金。鉴定条放在下方滚动区，避免挤占固定配装区。
