# 51 拖入占用装备／技能槽自动替换

用户明确要求：装备或卡牌拖入已占用格子直接替换。

规则：
- 仓库→占用槽：旧物回仓库。
- 装备/技能槽→同类占用槽：交换两实例位置。
- 背包/安全箱→占用槽：旧物尝试回来源位置（含旋转），否则普通背包first-fit；不自动放入安全箱，放不下整体拒绝。
- 待拾取区→占用槽：旧物回当前待拾取区，可继续拾取。
- 类型不符、未解锁、战斗锁定依旧拒绝。背包与安全箱格子本身不新增覆盖规则。
- 所有替换均一次事务保存，保留实例、星级、绑定、数量；校验和存档失败无部分提交。
- 悬停只高亮目标一格并标“替换”；二级预览的快捷装备仍优先空栏，不未经明确选位替换。
